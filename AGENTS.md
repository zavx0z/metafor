# MetaFor: правила разработки для агентов

Канонический project skill репозитория —
`.agents/skills/metafor-dev/SKILL.md`. Для любой нетривиальной разработки,
диагностики, запуска контура или живой приёмки MetaFor агент обязан использовать
его как маршрутизатор действий.

До изменения проверить skill:

```bash
bun .agents/skills/metafor-dev/scripts/metafor-dev.mjs validate
```

Для выбранных или уже изменённых путей получить impact-план и не обходить
неизвестную область:

```bash
bun .agents/skills/metafor-dev/scripts/metafor-dev.mjs impact --check --paths <paths...>
```

Контур проверять через `doctor`, а исполняемые сценарии — только через `run`.
Внутренние helper-скрипты skill напрямую не вызывать. Сначала нужны
детерминированные тесты и сборки, затем относящаяся к изменению живая приёмка.

При изменении команд, портов, health-контрактов, генераторов, host-инструментов
или пользовательского сценария одновременно обновлять MetaFor Dev. В проектном
коде оставлять продукт и автотесты; development-обвязку размещать в skill.
