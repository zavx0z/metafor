# Roadmap: Развитие UI-системы с эффектом "Frosted Glass"

## 🎯 Цель

Реализовать современную UI-систему для 3D-приложений на WebGPU с:

1. **Эффектом "жидкого стекла"** (frosted glass) через многопроходный рендеринг
2. **Базовыми UI-компонентами** (Panel, Button, Image)
3. **Мощной системой верстки** на основе собственного Flexbox-расчета

## 📊 Контекст

- Уже реализована базовая система верстки через собственные UI-расчеты
- Есть текстовый рендеринг (Text, TrueTypeFont)
- Работает система координат с преобразованием пиксели↔метры
- Текущий UI рендерится как простые полупрозрачные плоскости

## 🚀 Ожидаемый результат

1. **Визуальный эффект:** UI-панели с размытием фона (как в Vision Pro)
2. **Компоненты:** Готовые к использованию Panel, Button, Image
3. **Производительность:** Оптимизированный пайплайн с compute-шейдерами для размытия
4. **API:** Интуитивный декларативный API для создания интерфейсов

## 📅 Приоритеты

1. **Фундамент эффекта стекла** (материалы, текстуры, compute-шейдеры)
2. **Базовые компоненты** (Panel как основа для всего)
3. **Интерактивность** (Button с состояниями)
4. **Визуальный контент** (Image для текстур)

## 🔗 Связанные файлы проекта

- `src/ui/UIDisplay.ts` - корневой контейнер UI
- `src/renderer/index.ts` - WebGPU рендерер
- `src/materials/Material.ts` - база для материалов
- `src/core/Object3D.ts` - базовая сущность сцены

## 📋 Подзадачи

1. **01-glass-material-panel.md** - Материал GlassMaterial и компонент GlassPanel
2. **02-offscreen-textures-renderer.md** - Offscreen-текстуры и расширение рендерера
3. **03-compute-blur-shaders.md** - Compute-шейдеры для размытия по Гауссу
4. **04-multipass-rendering-pipeline.md** - Многопроходный конвейер рендеринга
5. **05-basic-ui-components.md** - Базовые UI-компоненты (Panel, Button, Image)

## 📊 Метрики успеха

- FPS остаётся стабильным (>60fps) с включенным эффектом стекла
- Размытие фона обновляется в реальном времени при движении камеры
- UI-компоненты корректно работают с системой верстки
- Память GPU используется эффективно (текстуры пересоздаются только при ресайзе)
