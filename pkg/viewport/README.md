## ✨ Возможности

- 🎯 **Бесконечная область просмотра** с настраиваемой координатной сеткой
- 🔍 **Плавное масштабирование** с поддержкой жестов
- 🖱️ **Множество способов навигации**:
    - Перетаскивание мышью
    - Жесты тачпада
    - Клавиатурное управление
- 📱 **Кроссплатформенность**:
    - Десктоп (Windows, MacOS, Linux)
    - Мобильные устройства
    - Планшеты
- ⚡ **Оптимизированная производительность**:
    - Аппаратное ускорение
    - Эффективная система рендеринга
    - Умное обновление состояния
- 🎨 **Гибкая система рёбер**:
    - Canvas-рендеринг
    - Автоматическое обновление
    - Настраиваемые стили
- 🛠️ **Расширяемая архитектура**:
    - Web Components
    - Система событий
    - Программное API
- 🚀 **Нулевые зависимости**:
    - Чистый JavaScript
    - Без внешних библиотек
    - Минимальный размер
