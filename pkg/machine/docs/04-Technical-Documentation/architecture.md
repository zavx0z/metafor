# Отложенная инициализация графического представления

## Введение

Quantum Atom поддерживает визуализацию состояний и переходов через WebComponent. Для оптимизации производительности используется механизм отложенной инициализации графического представления.

## Механизм работы

### 1. Создание атома с визуализацией

При создании атома с опцией `graph: true`, система:

- Не блокирует создание атома
- Запускает асинхронную загрузку WebComponent
- Добавляет метод `graph()` для доступа к компоненту

```javascript
const atom = Atom("Example")
  .create({
    id: "example",
    state: "IDLE",
    graph: true // Включение визуализации
  })
````

### 2. Отложенный доступ

Метод `graph()` возвращает Promise с компонентом визуализации:

```javascript
const graphComponent = await atom.graph();
```

Преимущества:

- Не блокирует основной поток
- Можно вызывать сразу после создания атома
- Promise резолвится автоматически после загрузки
- Поддерживает множественные вызовы

### 3. Жизненный цикл WebComponent

1. Асинхронная загрузка модуля
2. Регистрация компонента в DOM
3. Инициализация с данными атома
4. Подключение к обновлениям состояния

### 4. Интеграция с DOM

WebComponent:

- Создается автоматически при первом вызове `graph()`
- Встраивается в указанный контейнер
- Обновляется при изменении состояния атома
- Поддерживает интерактивное взаимодействие

## Пример использования

```javascript
// Создание атома с визуализацией
const atom = Atom("Example")
  .states("IDLE", "LOADING", "SUCCESS", "ERROR")
  .context({}).collapses([]).internal({}).actions({})
  .create({
    id: "example",
    state: "IDLE",
    graph: true
  })

// Получение компонента графа
const graph = await atom.graph()

// Компонент готов к использованию
console.log(graph.id) // "/example"
```

## Преимущества подхода

1. Производительность:

    - Быстрая инициализация атома
    - Отложенная загрузка визуализации
    - Оптимизированные обновления DOM

2. Удобство разработки:

    - Простой API через Promise
    - Автоматическая инициализация
    - Поддержка асинхронного доступа

3. Надежность:
    - Безопасная загрузка компонентов
    - Корректная работа с DOM
    - Обработка ошибок загрузки
