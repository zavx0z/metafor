# Core: Управление и совместный доступ в Quantum Atom

## Введение

`Core` представляет собой механизм управления временными данными и сервисами атома. Он используется для выполнения логики, хранения данных и обеспечения совместного доступа через `create.core`. Эта система позволяет атомам взаимодействовать, сохраняя изоляцию и контроль над изменениями.

---

## Ключевые возможности

- **Изолированность:** Данные и сервисы `Core` по умолчанию привязаны к одному атому.
- **Гибкость:** Поддержка API, временных ресурсов, кэшей и асинхронных операций.
- **Совместное использование:** Переданные данные через `create.core` доступны другим атомам без необходимости копирования.

---

## Волатильное состояние

`Core` предназначен для работы с данными, которые:

- **Не сохраняются** в снапшотах.
- **Не передаются автоматически** между атомами.
- Используются для работы с временными ресурсами, такими как промисы, таймеры и DOM-элементы.

---

## Общий доступ через Core

`Core` предоставляет функционал, напоминающий общую память (shared memory). Данные передаются через ссылку, что позволяет атомам совместно использовать изменения, не теряя предсказуемости.

### Особенности

- **Мутабельность:** Данные можно изменять (например, добавлять элементы в массив), но нельзя заменять целиком.
- **Контроль:** Структура данных защищается в атоме с помощью `Object.freeze`, сохраняя возможность модификации содержимого.

### Поддерживаемые типы данных

- **Объекты:** `Object`, `Array`, `Map`, `Set` — изменяемые типы, подходящие для совместного использования.
- **Специальные объекты:** `Date`, `RegExp`, `Error`.
- **Функции и промисы:** Для реализации логики и обработки асинхронных операций.

Примитивы, такие как `string` и `number`, не подходят для совместного использования, так как их изменение требует полной замены.

---

## Доступ к ядру

### Использование `self`

`self` рекомендуется использовать для предсказуемого доступа к данным и методам ядра, особенно в ситуациях, где контекст вызова теряется, например:

- Обработчики событий.
- Колбэки.
- Асинхронные операции.

### Использование `this`

`this` может быть полезен для работы с ядром в стандартных функциях, где контекст вызова сохраняется. Используйте `this` только в случаях, где вы уверены в его привязке.

---

## Рекомендации

1. **Используйте `self`:** Для безопасного доступа и управления данными ядра.
2. **Работайте с временными данными:** Храните ресурсы, промисы, таймеры и подписки.
3. **Избегайте сериализации:** Не сохраняйте данные, требующие передачи между атомами или их преобразования.
