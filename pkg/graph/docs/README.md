# @quantum/graph

## Описание

`@quantum/graph` - это среда разработки и визуализации интерфейсов взаимодействия между различными системами (человек,
компьютер, нейросеть, автомобиль, гаджеты) в виде интерактивных графов. Позволяет моделировать и отображать:

- Состояния систем и их взаимосвязи
- Переходы между состояниями
- Триггеры и события
- Потоки данных между компонентами

Основная цель - предоставить наглядный способ проектирования и отладки сложных взаимодействий в современных
киберфизических системах.

## Ключевые сценарии использования

- Проектирование систем с AI-компонентами
- Отладка сложных многокомпонентных систем
- Real-time мониторинг состояний

### Уровни отображения системы

`@quantum/graph` поддерживает различные уровни абстракции для визуализации систем. Это позволяет пользователям настраивать детализацию отображаемой информации в зависимости от их потребностей. Уровни могут включать:

- **Высокий уровень**: Общий обзор системы, показывающий основные компоненты и их взаимодействия.
- **Средний уровень**: Более детализированное представление, включающее подкомпоненты и их связи.
- **Низкий уровень**: Подробное отображение всех элементов и их состояний, включая внутренние процессы и данные. Подробнее об отображении триггеров на низком уровне можно прочитать [здесь](./docs/low-level-trigger-visualization.md).

Эти уровни помогают пользователям эффективно управлять сложностью визуализируемой системы и сосредотачиваться на наиболее важных аспектах в зависимости от текущих задач.

## Основные возможности

- Визуализация состояний систем в виде узлов графа
- Отображение триггеров состояний в виде направленных рёбер
- Интерактивное взаимодействие с графом
- Автоматическая раскладка элементов с помощью алгоритма ELK
- Настраиваемый внешний вид через CSS переменные
- Поддержка WebSocket для real-time обновлений
- Гибкие уровни абстракции для оптимального представления данных и бизнес-логики под конкретные задачи

### Базовая интеграция

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <title>quantum-graph</title>
  <script type="module">
    import "@quantum/graph/index"
  </script>
</head>
<body>
<quantum-graph></quantum-graph>
</body>
</html>
```

### WebSocket подключение

Для real-time обновлений используется WebSocket соединение:

```javascript
const ws = new WebSocket(`ws://${window.location.hostname}:4440/debug`)
const channel = new BroadcastChannel("graph")

ws.onmessage = (event) => {
  channel.postMessage(JSON.parse(event.data))
}
```

## Компоненты

### quantum-graph

Основной компонент для отображения графа. Управляет размещением и отрисовкой всех элементов.

### graph-atom

Группирует связанные состояния машины. Содержит заголовок и набор узлов.

### graph-state

Представляет отдельное состояние машины. Содержит:

- Заголовок с названием состояния
- Параметры с входными/выходными сокетами
- Поддержку drag-n-drop

### graph-parameter

Отображает параметр состояния с входным и выходным сокетами.

### graph-socket

Визуализирует точку подключения для переходов между состояниями.

## Стилизация

Внешний вид настраивается через CSS переменные:

```css
:root {
  --font-color: #dcdcdc;
  --background-blur: 2px;
  --node-background: rgba(40, 40, 40, 0.4);
  --socket-color: #4caf50;
  --highlight-color: rgba(255, 255, 255, 0.1);
  --grid-step: 100px;
  --background-color: #121212;
  --node-shadow: 0 0 8px 2px rgba(0, 0, 0, 0.4);
}
```

## Конфигурация раскладки

Алгоритмы раскладки используются для автоматического позиционирования элементов графа. Elk Eclipse (ELK) - это
алгоритмы, которые позволяют расположить элементы графа в удобном для восприятия виде.

## Разработка

```bash
# Установка зависимостей
bun i

# Запуск dev-сервера
bun run dev

# Запуск тестов
bun run test:pipeline
bun run test:triggers
```

## Требования

- Bun 1.0+
- Современный браузер с поддержкой Web Components
- WebSocket для real-time обновлений
