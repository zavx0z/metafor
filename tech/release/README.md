# Выпуск

Выпуск — подготовка и публикация полного согласованного состава версий пакетов.
Он имеет три варианта: первый выпуск, новый выпуск и продолжение прерванного.
Опубликованная версия пакета используется без повторной сборки. Доставка и
активация опубликованного выпуска принадлежат следующим процессам.

[Сценарий выпуска](spec/scenario.spec.ts) задаёт варианты через `describe.each`:
общие случаи объявлены один раз, частные оформлены через `describe.skipIf` с пояснением применимости.
Все проверки имеют статус `test.todo`: реализация выпуска и его публичный API
ещё не добавлены. Текущий механизм Cosmos к этому пакету не подключён.
