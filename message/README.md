# Особенности использования patch вместо patches

В данном проекте используется термин patch вместо patches. Это является осознанным отклонением от стандарта, поскольку патчи применяются к иммутабельному контексту, который содержит только простые типы (в том числе внутри массивов). Благодаря этому нет необходимости в поддержке множественных патчей одновременно — достаточно одного patch для описания изменений.

Такой подход упрощает реализацию и делает работу с контекстом более предсказуемой, поскольку каждый patch всегда относится к простым значениям, а не к вложенным или сложным структурам.
