# Обзор проекта MetaFor

## Тип проекта

Это JavaScript/TypeScript монорепозиторий, использующий Bun в качестве среды выполнения и менеджера пакетов. Проект реализует фреймворк для создания веб-компонентов на основе конечных автоматов под названием "MetaFor".

## Структура проекта

```
├── atom/                 # Основная реализация атома (конечный автомат)
├── infra/                # Инфраструктурные пакеты
│   ├── inspect/          # Инструменты отладки и инспектор
│   ├── mesh/             # Демонстрационное приложение 3D/WebXR
│   ├── test/             # Инфраструктура тестирования
│   └── virtual/          # Реализация виртуального DOM
├── meta/                 # Основная реализация фреймворка MetaFor
├── shared/               # Общие ресурсы и скрипты
└── package.json          # Конфигурация рабочего пространства
```

## Основные компоненты

### Фреймворк MetaFor (@metafor/meta)

Основной фреймворк, предоставляющий декларативный способ создания веб-компонентов с конечными автоматами. Основные особенности:

- Типизированный контекст, состояния, процессы, реакции и представления
- Общение между компонентами на основе сообщений
- Система позиционных путей для иерархии VDOM
- Расширенные фильтры реакций с доступом к контексту
- Рендеринг на основе шаблонов с использованием @zavx0z/template

### Система атомов (@metafor/atom)

Основа реализации конечного автомата:

- Основной класс Atom, расширяющий класс Strong
- Управление состояниями с процессами и действиями
- Управление событиями через EM (Event Manager)
- Интерфейс self-информации для идентификации атома

### Инфраструктурные пакеты

#### Inspect (@metafor/inspect)

Инструменты отладки, включая:

- Веб-базированный отладчик с элементами управления воспроизведения/паузы/шага
- Компонент визуализации стека
- Функциональность логгера

#### Mesh (infra/mesh)

Демонстрационное приложение галереи 3D/WebXR, демонстрирующее возможности фреймворка MetaFor:

- Интеграция Three.js для 3D-рендеринга
- Поддержка WebXR для VR-опыта
- Использование компонентов MetaFor для UI и управления состоянием

#### Virtual (@metafor/virtual)

Реализация виртуального DOM поверх системы атомов.

## Используемые технологии

- **Среда выполнения**: Bun (JavaScript/TypeScript среда выполнения)
- **Язык**: TypeScript
- **3D графика**: Three.js
- **Веб-компоненты**: Native Web Components API
- **Управление состоянием**: Пользовательская реализация конечного автомата
- **Шаблонизация**: @zavx0z/template
- **Управление контекстом**: @zavx0z/context

## Структура рабочего пространства

Проект использует npm рабочие области со следующими пакетами:

- `@metafor/meta` - Основной фреймворк
- `@metafor/atom` - Основная система атомов
- `@metafor/inspect` - Инструменты отладки
- `@metafor/virtual` - Реализация виртуального DOM
- `mesh` - Демо-приложение 3D галереи

## Команды сборки и запуска

```bash
# Установка зависимостей
bun install

# Обновление зависимостей
bun run upd

# Сборка всех пакетов
bun run build

# Генерация определений типов
bun run typegen

# Очистка артефактов сборки
bun run clear
```

### Команды для конкретных пакетов

У каждого пакета есть свои собственные скрипты сборки:

- `build`: Сборка продакшн и девелоперских версий
- `typegen`: Генерация определений TypeScript
- `clear`: Удаление артефактов сборки
- `pub`: Публикация пакета (для публичных пакетов)

## Руководство по разработке

1. Использовать TypeScript для всех реализаций
2. Следовать паттерну конечного автомата для логики компонентов
3. Использовать веб-компоненты для элементов пользовательского интерфейса
4. Использовать систему общения на основе сообщений для межкомпонентного взаимодействия
5. Использовать систему позиционных путей для управления иерархией VDOM
6. Использовать предоставленные инструменты отладки во время разработки

## Ключевые архитектурные концепции

1. **Изоляция атомов**: Каждый атом имеет полную изоляцию с независимой реализацией
2. **Обмен сообщениями**: Все взаимодействия между атомами происходят через патчи в сообщениях
3. **Позиционные пути**: Каждый атом имеет уникальный позиционный путь в VDOM (например, "0/1/2")
4. **Система реакций**: Декларативная система реакций с обширными возможностями фильтрации
5. **Рендеринг на основе шаблонов**: Использует @zavx0z/template для рендеринга с поддержкой JavaScript-выражений
