# 🌌 MetaFor: Онтология распределённого бытия

> *«Код как метафора устройства Вселенной»*

MetaFor — это попытка выразить в архитектуре программного обеспечения фундаментальные принципы организации реальности, заимствованные из:

- квантовой механики (суперпозиция, коллапс, наблюдатель),
- теории поля (браны, возмущения, эволюция),
- монадологии Лейбница (индивидуальные сущности с намерением),
- теории проекции (многоуровневое проявление).

Это не просто фреймворк. Это **онтологическая модель**, где каждый уровень кода соответствует уровню бытия.

---

## 🌀 Четыре уровня реальности

### BOUNDARY — Поле (квантовый субстрат)

> *«То, из чего соткана ткань бытия»*

Boundary — это уровень чистой механики. Здесь нет смысла, только вычисление.

- Состояния — индексы, не имена
- Переходы — bytecode, не логика
- Эволюция — детерминированная, параллельная, на GPU

**Метафора:** Boundary — это квантовое поле, фундаментальная ткань реальности, где всё возможно, но ничего не имеет значения само по себе.

**Пространство-время:**

- **Heap** — пространство (где находятся данные полей)
- **Lock** — время (когда зафиксировано состояние)
- **Bytecode** — законы физики (детерминированные правила эволюции)
- **TAKT** — квант времени (дискретный шаг эволюции)

---

### MONAD — Сущность (носитель намерения)

> *«То, что определяет КЕМ быть и КУДА стремиться»*

Monad — это уровень смысла. Здесь абстрактные индексы обретают имена, а переходы — цели.

- Состояния — `"IDLE"`, `"PATROL"`, `"DEAD"` — несут семантику
- Намерения (`intention`) — указывают, какой процесс должен исполниться
- События рождения (`birth`) — момент проявления сущности в поле

**Метафора:** Monad — это индивидуальная душа, монада Лейбница: зеркало Вселенной с собственной точкой зрения и вектором стремления.

---

### FORCE — Взаимодействие (фундаментальные силы)

> *«То, что связывает уровни в единое целое»*

Force — это чистые функции, применяющие эффекты без нарушения изоляции уровней.

- **Gravity** — иерархия и порядок
- **Electromagnetic** — обмен событиями и информацией
- **Strong** — удержание состояния, стабильность
- **Weak** — изменение, распад, трансформация

**Метафора:** Force — это фундаментальные взаимодействия физики, но в онтологии MetaFor: силы, которые позволяют смыслу (MONAD) влиять на механику (BOUNDARY) и проявляться в форме (BULK).

---

### BULK — Проявление (феноменальный мир)

> *«То, что мы видим — формы, цвета, движения»*

Bulk — это уровень восприятия. Здесь абстрактные сущности обретают визуальную форму.

- Визуализация через `<meta-for>`
- Иерархия акторов
- Стилизация и взаимодействие

**Метафора:** Bulk — это феноменальный мир, то, что доступно наблюдению. Это не «истина», а проекция более глубоких уровней.

---

## 🔄 TAKT-ритм: пульс эволюции

Система живёт в детерминированном цикле **TAKT** — ритме, в котором разворачивается время:

1. **Commit** — синхронизация топологии сущностей с полем
2. **Birth** — рождение: сущность впервые проявляется в поле
3. **Runtime** — эволюция: поле вычисляет переходы по законам
4. **Interpretation** — осмысление: монада интерпретирует изменение
5. **Execution** — действие: сила исполняет намерение

Это не алгоритм. Это **ритм бытия**, в котором механика и смысл встречаются.

---

## 🔒 Lock: метафора времени

Lock — это не технический флаг. Это онтологический маркер **времени** в пространстве-времени Boundary:

| Свойство | Проявление в MetaFor | Физический аналог |
| -------- | -------------------- | ----------------- |
| **Однонаправленность** | Boundary ставит → Force снимает | Стрела времени |
| **Фиксация момента** | `lock = 1` замораживает эволюцию | Настоящее фиксировано |
| **Дискретность** | TAKT-цикл (шаги эволюции) | Планковское время |
| **Необратимость** | После `releaseLock()` нет возврата к старому состоянию | Энтропия |

**Механика:**

- **Boundary ставит lock** — Закон фиксирует изменение (детерминизм)
- **Monad интерпретирует** — Смысл решает, что делать с изменением (свобода воли)
- **Force исполняет** — Действие завершает цикл (проявление в мире)
- **ReleaseLock** — Переход к новому такту (время движется дальше)

**Lock — это граница между «сейчас» и «потом».**

Это момент, когда детерминизм поля встречается со свободой воли сущности.

## 🧭 Принцип соответствия

Каждый уровень говорит на своём языке, потому что его природа требует этого:

| Уровень | Язык | Онтологический смысл |
| ------- | ---- | -------------------- |
| **MONAD** | Имена (`"IDLE"`, `"hp"`) | Семантика — язык смысла для наблюдателя |
| **BOUNDARY** | Индексы (`0`, `1`, `2`) | Механика — язык вычисления для поля |
| **FORCE** | Чистые функции | Взаимодействие — язык эффектов без состояния |
| **BULK** | Визуальные формы | Проявление — язык восприятия для сознания |

**Ключевой принцип:** Смысл и механика разделены, но гармонично связаны через конвертацию и события.

## 🌟 Философские принципы MetaFor

### Минимальная ответственность

Каждый уровень отвечает только за свою область бытия:

- Boundary не знает смысла — только вычисляет
- Monad не вычисляет GPU — только интерпретирует
- Bulk не управляет состояниями — только проявляет

### Голографический принцип

Каждое событие содержит информацию о всей системе:

- История импульсов (`histories`)
- Снапшоты для отката (`checkpoints`)
- Возможность «путешествия во времени» (`rollbackSystem`)

### Монадическая композиция

Цепочки вычислений с состоянием отражают поток времени:

- Процессы: `action → success/error`
- Реакции: `filter → equal`
- TAKT-цикл: `commit → birth → runtime → releaseLock`
