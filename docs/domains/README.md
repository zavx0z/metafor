# Доменные контракты

Это индекс действующих проверяемых законов доменов. Документ-владелец может
находиться рядом с кодом домена; физическое расположение не меняет его статус.
Общие правила приоритета описаны в [карте документации](../README.md).

Сейчас выделены самостоятельные контракты:

- [Boundary](../../boundary/DOMAIN.md) — canonical persistence, identity,
  materialization и commit.
- [Matrix](MATRIX.md) — State/Transition, Process lifecycle и инкрементальные
  структурные изменения.
- [Energy](ENERGY.md) — исполнение Process, живые runtime-сущности и их
  декларация в DSL.
- [Bulk layout](../../bulk/gravity/layout/CONTRACT.md) — геометрия рекурсивного
  проявления.

Для Dark и Bulk целиком полного доменного контракта пока нет. До его появления
наблюдаемая общая схема описана в [ARCHITECTURE.md](../ARCHITECTURE.md), а
центральная граница Force — в [FORCE.md](../FORCE.md).
