# Доменные контракты

Здесь находятся действующие проверяемые законы доменов MetaFor. Документ домена
объясняет его ответственность, входы и выходы, инварианты, производительность и
тесты. Код и public types реализуют контракт, а тесты доказывают его на
конкретных сценариях.

Сейчас выделены самостоятельные контракты:

- [Matrix](MATRIX.md) — State/Transition, Process lifecycle и инкрементальные
  структурные изменения.
- [Energy](ENERGY.md) — исполнение Process, живые runtime-сущности и их
  декларация в DSL.

Документация остальных доменов переносится сюда по мере их следующего
содержательного изменения. До этого их наблюдаемая общая схема описана в
[ARCHITECTURE.md](../ARCHITECTURE.md), а Force — в [FORCE.md](../FORCE.md).
