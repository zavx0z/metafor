# Основные принципы MetaFor

## 1. Контекст как единственный источник истины

В отличие от классических подходов, где состояние является первичным, в MetaFor первичен контекст:

- Контекст содержит все данные, необходимые для работы частицы
- Состояние определяется на основе контекста через триггеры
- Изменение контекста может привести к изменению состояния

## 2. Реактивность на основе контекста

MetaFor автоматически реагирует на изменения контекста:

- Любое изменение контекста запускает проверку триггеров
- Если триггер сработал, происходит переход в новое состояние
- Переходы между состояниями происходят автоматически

## 3. Декларативное определение переходов

- Переходы между состояниями определяются декларативно через триггеры
- Триггеры описывают условия, при которых должен произойти переход
- Система автоматически выбирает подходящий переход на основе текущего контекста

## 4. Изоляция и композиция

- Каждая частица является изолированной единицей с собственным контекстом и состоянием
- Частицы могут взаимодействовать друг с другом через реакции
- Сложные системы строятся из простых частиц через композицию

## 5. Предсказуемость и отладка

- Все изменения состояния происходят через явно определенные переходы
- Каждый переход имеет четкие условия срабатывания
- Система предоставляет инструменты для отладки и визуализации переходов

## 6. Разделение данных и представления

- Частица отвечает только за управление данными и состоянием
- Представление (UI) может быть подключено к частице, но не является ее частью
- Это позволяет использовать одну и ту же частицу с разными UI-фреймворками

## 7. Асинхронность и побочные эффекты

- Асинхронные операции и побочные эффекты инкапсулируются в действиях
- Действия выполняются при входе в состояние
- Результаты действий отражаются в контексте, что может привести к новым переходам
