# Режим разработки в MetaFor

## Введение

Режим разработки (Development Mode) в MetaFor предоставляет набор инструментов и функций, которые помогают разработчикам создавать, отлаживать и тестировать приложения. Этот режим включает расширенную валидацию, подробные сообщения об ошибках и инструменты визуализации.

## Основные возможности режима разработки

### 1. Валидация компонентов частицы

В режиме разработки MetaFor автоматически проверяет корректность определения компонентов частицы:

- **Валидация состояний** — проверка уникальности и корректности имен состояний
- **Валидация контекста** — проверка типов и значений по умолчанию
- **Валидация коллапсов** — проверка корректности правил перехода между состояниями
- **Валидация действий** — проверка наличия и корректности определения действий

При обнаружении ошибок в консоль выводятся подробные сообщения с указанием проблемы и рекомендациями по ее исправлению.

### 2. Расширенное логирование

Режим разработки включает расширенное логирование, которое помогает отслеживать жизненный цикл частицы:

- **Логирование создания частицы** — информация о создании частицы и ее начальном состоянии
- **Логирование изменений контекста** — подробная информация об изменениях контекста
- **Логирование переходов между состояниями** — информация о переходах между состояниями и сработавших триггерах
- **Логирование выполнения действий** — информация о выполнении действий и их результатах

```javascript
// Пример вывода в консоль в режиме разработки
// [MetaFor] Создана частица "TodoList" с начальным состоянием "IDLE"
// [MetaFor] Изменение контекста в частице "TodoList": { items: [...], isLoading: true }
// [MetaFor] Переход в частице "TodoList": IDLE -> LOADING (триггер: isLoading)
// [MetaFor] Выполнение действия "fetchItems" в частице "TodoList"
```

### 3. Визуализация состояний и переходов

Режим разработки предоставляет возможность визуализации состояний и переходов частицы:

```javascript
const todoAtom = MetaFor("TodoList")
  .states("IDLE", "LOADING", "LOADED", "ERROR")
  .context((t) => ({
    /* ... */
  }))
  .transitions([
    /* ... */
  ])
  .create({
    state: "IDLE",
    graph: true // Включение визуализации
  });

// Получение компонента визуализации
todoAtom.graph().then(component => {
  document.getElementById('graph-container').appendChild(component);
});
```

Компонент визуализации отображает:

- **Текущее состояние частицы** — выделяется цветом
- **Возможные переходы** — отображаются стрелками между состояниями
- **Триггеры переходов** — отображаются на стрелках
- **Контекст частицы** — отображается в виде JSON

### 4. Отладка триггеров

Режим разработки позволяет отлаживать триггеры переходов между состояниями:

```javascript
// Проверка, сработает ли триггер при заданном контексте
const willTrigger = todoAtom.debug.checkTrigger({
  from: "IDLE",
  to: "LOADING",
  context: { isLoading: true }
});

console.log(willTrigger); // true или false

// Получение информации о всех возможных переходах из текущего состояния
const possibleTransitions = todoAtom.debug.getPossibleTransitions();

console.log(possibleTransitions);
// [
//   { to: "LOADING", trigger: { isLoading: true }, action: "fetchItems" },
//   { to: "ERROR", trigger: { error: { isNull: false } } }
// ]
```

### 5. Временная шкала изменений

Режим разработки включает временную шкалу изменений, которая позволяет отслеживать историю изменений частицы:

```javascript
// Получение истории изменений частицы
const history = todoAtom.debug.getHistory();

console.log(history);
// [
//   { type: "CREATE", state: "IDLE", context: { ... }, timestamp: 1623456789 },
//   { type: "UPDATE", context: { isLoading: true }, timestamp: 1623456790 },
//   { type: "COLLAPSE", from: "IDLE", to: "LOADING", trigger: { isLoading: true }, timestamp: 1623456791 },
//   { type: "ACTION", name: "fetchItems", timestamp: 1623456792 },
//   { type: "UPDATE", context: { items: [...], isLoading: false }, timestamp: 1623456793 },
//   { type: "COLLAPSE", from: "LOADING", to: "LOADED", trigger: { items: { length: { gt: 0 } } }, timestamp: 1623456794 }
// ]
```

## Практические рекомендации

1. **Всегда используйте режим разработки во время разработки** — это поможет выявить ошибки на ранних стадиях.

2. **Обращайте внимание на предупреждения в консоли** — они могут указывать на потенциальные проблемы в вашем коде.

3. **Используйте визуализацию для понимания логики переходов** — это особенно полезно для сложных частиц с множеством состояний.

4. **Отлаживайте триггеры при неожиданном поведении** — это поможет понять, почему не происходит ожидаемый переход.

5. **Анализируйте историю изменений при отладке** — это поможет понять последовательность событий, приведших к текущему состоянию.

## Заключение

Режим разработки в MetaFor предоставляет мощные инструменты для разработки, отладки и тестирования приложений. Используя эти инструменты, вы можете создавать более надежные и предсказуемые приложения, а также быстрее находить и исправлять ошибки.
