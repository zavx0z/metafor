# Онтология

Действующие онтологические решения MetaFor фиксируются в документации доменов
этого репозитория и проверяются public types и тестами. Внешний
`zavx0z/concept` хранит историю исследования, но не имеет автоматического
приоритета над контрактом проекта.

Runtime-код сам по себе не создаёт новый онтологический закон. Изменение
identity, causality или cardinality сначала должно быть явно описано в
соответствующем документе из [`docs/domains`](domains/README.md).

Наблюдаемая структура реализации описана в
[ARCHITECTURE.md](ARCHITECTURE.md).
