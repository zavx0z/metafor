# Философия

Каноническая философия MetaFor ведётся в
[репозитории `zavx0z/concept`](https://github.com/zavx0z/concept).

Этот runtime-репозиторий не устанавливает и не пересказывает философские законы.
Такое разделение не позволяет текущей реализации незаметно стать источником
концептуальной истины.

Здесь документируются только исполняемые механизмы:

- [архитектура реализации](ARCHITECTURE.md);
- [реализованный Force contract](FORCE.md);
- [локальная разработка и проверки](DEVELOPMENT.md).
