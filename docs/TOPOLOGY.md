# Topology

Канонические определения и законы topology MetaFor ведутся в
[репозитории `zavx0z/concept`](https://github.com/zavx0z/concept).

Этот runtime-файл намеренно не определяет частицы, связи, identity, branching
или visual laws. Реализованные SQLite tables, projections и TypeScript types
являются механизмами текущего runtime и не получают концептуального авторитета
из-за своего существования в коде.

Точки реализации перечислены в [ARCHITECTURE.md](ARCHITECTURE.md), а DSL и
Matter, необходимые для дальнейшего аудита, сохранены без семантического
переопределения.
