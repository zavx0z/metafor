# Topology

Действующие определения topology должны находиться в документации домена,
который ими владеет, внутри этого репозитория. Исторические формулировки из
внешнего `zavx0z/concept` могут использоваться как материал, но не как скрытый
контракт.

Реализованные SQLite tables, projections и TypeScript types сами по себе не
создают новый закон: изменение связей, identity, branching или visual behavior
сначала формулируется и согласуется в проектной документации.

Точки реализации перечислены в [ARCHITECTURE.md](ARCHITECTURE.md), а DSL и
Matter, необходимые для дальнейшего аудита, сохранены без семантического
переопределения.
