# @metafor/atom

[← Корень](../README.ru.md) | **Русский** | [English](README.md)

## Назначение

- Материализует схемы из `@metafor/meta` и удерживает их в поле (`Field`, `Gravity`, `EM`, `Weak`, `Strong`).
- Управляет жизненным циклом атома: инициализация, суперпозиция состояний, процессы, реакции, история импульсов.
- Предоставляет API для управления иерархией (`Atom.fromSchema`, `Atom.append`, `Atom.createSibling`) и для наблюдения за импульсами.

## Базовые понятия

### Self

```ts
atom.self // { atom: string, meta: string, path: string }
```

- `self.path` — позиционный путь (`0/1/2`), формируется `Field`.
- Полный `Self` (с `destroy`) доступен в реакциях и процессах, а `SelfInfo` — в фильтрах.

### Field

- Хранит все атомы, их родителя, порядок и историю (`Photon`).
- Предоставляет методы резервирования позиций и снапшоты для откатов.

### EM (Electromagnetic)

- Транспортирует импульсы (`Photon`) между атомами.
- Позволяет замораживать стек (`EM.break()` / `EM.resume()`) и шагать по импульсам (инспекторы).

### Кодирование информации фотоном

- **Интенсивность**: количество патчей внутри `photon.impulses` отражает «яркость» события (например, success с большим количеством обновлений).
- **Частота/цвет**: комбинация `meta` + `atom` определяет источник — как длина волны в оптике.
- **Поляризация**: `path` и `op` JSON Patch задают направление и тип изменения (контекст, состояние, корень).
- **Фаза**: `timestamp` и позиция в стеке EM фиксируют относительное время и порядок.
- **Суперпозиция**: состояние атома выступает детектором; реакция решает, поглощать ли фотон.

Эта модель позволяет актору реагировать на любой импульс, просто читая его свойства, без прямых ссылок на отправителя.

## Создание и иерархия

### `Atom.fromSchema`

```ts
const atom = Atom.fromSchema({
  meta: userProfile,
  id: "user-1",
  context: { userId: 42 },
  core: { cache: new Map() },
  path: "0/1", // опционально, будет зарезервирован заранее
})
```

- Если `path` не указан, он генерируется автоматически.
- Контекст и core инициализируются из схемы и поверх накладываются значения из конфигурации.

### `Atom.createSibling(targetId, meta, options)`

- Резервирует позицию рядом с существующим атомом (до/после).
- Создаёт новый атом в следующей макротаске, не блокируя родителя.

### `Atom.append(parentId, meta, options)`

- Добавляет ребёнка к определённому родителю (или к корню, если `parentId === null`).
- Индекс вычисляется как количество детей родителя.

## Жизненный цикл

1. **init** — измеряет суперпозицию (`measurement`) и коллапсирует в начальное состояние.
2. **transition** — меняет состояние и запускает процесс, если он есть.
3. **action → success/error** — исполнение процесса с обновлением контекста через `update`.
4. **reactions** — обрабатывают входящие импульсы; при срабатывании могут вызвать `measurement`.
5. **destroy** — удаляет атом из поля, очищает core (см. `process.destroy()`).

Все публичные методы обёрнуты декоратором `@EM.it`, который автоматически генерирует импульс и рассылает его всем подписчикам (другим атомам, Inspect, Virtual).

## Работа с контекстом

```ts
atom.evaluate({ userName: "Neo" })
```

- `evaluate` синхронно обновляет контекст через `Update<Values>` из `@zavx0z/context`.
- Изменения транслируются как `Photon` с операцией `replace` по пути `/context`.

## Реакции во время исполнения

```ts
reactions.run({
  meta: photon.meta,
  atom: photon.atom,
  timestamp: photon.timestamp,
  patch,
  context: atom.λ,
  core: atom.core,
  state: atom.state,
  update: atom.evaluate,
  self: atom.self,
})
```

- Реакция срабатывает только если: состояние входит в список, фильтр вернёт условия и JSON Patch удовлетворит этим условиям.
- После успешного `equal` атом повторно измеряет суперпозицию (`measurement`) и может перейти в новое состояние.

## История и откаты

- `Field.histories` накапливает последние `MAX_PATCHES` импульсов; при превышении создаётся чекпоинт.
- `Field.createCheckpoint()` сохраняет снапшот всех атомов для дальнейшего восстановления.
- `Field.rollbackSystem(timestamp)` позволяет откатить поле к ближайшему чекпоинту ≤ timestamp.
