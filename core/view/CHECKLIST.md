## Чек-лист по условным атрибутам и выражениям

- [ ] Для простого значения используйте строку или `{ src, key? }`
- [ ] Для смешанного контента используйте `{ template, items }` с `${i}`
- [ ] Если выражение эквивалентно одному значению (`"${0}"`), `template` не нужен
- [ ] Если ровно одна переменная — лучше `{ src, key? }`, а не `{ template, items }`

Условные атрибуты:

- [ ] Короткая форма: `{ src, key?, true, false? }` (истина — строго `value === true`)
- [ ] Сложная форма: `{ template, items, true, false? }` (логическое выражение над `${i}`)
- [ ] Ветви `true/false` могут быть строкой или шаблоном `{ template, items }`
- [ ] Для булевых атрибутов непустая строка включает атрибут; пустая строка — не устанавливает

Массивы:

- [ ] Внутри массивов ссылки нормализуются в пути `src: string[]` с учётом `arrayContext`
- [ ] Вложенные массивы — путь накапливается

Совместимость:

- [ ] Старый формат `type: "conditional"` не допускается
