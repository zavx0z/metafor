## Формат условных атрибутов и выражений

Краткая спецификация нового формата для атрибутов в MetaFor View.

### 1) Простые значения

- Строка: `class: "btn"`
- Интерполяция: `class: { src: "context", key: "name" }`
- Шаблон: `class: { template: "btn-${0}", items: [{ src: "context", key: "size" }] }`

Оптимизации:

- Если шаблон эквивалентен одному значению (`"${0}"`), `template` опускается, используйте `{ src, key? }`.
- Если в выражении участвует ровно одна переменная, используйте короткую форму с `{ src, key? }` вместо `{ template, items }`.

### 2) Условное значение (по источнику)

```ts
// Истинность: строго val === true
disabled: { src: "context", key: "cannotEdit", true: "disabled" }

// Строковый атрибут
class: { src: "context", key: "isLarge", true: "btn-lg", false: "btn-sm" }

// Ветви могут быть шаблонами
class: {
  src: "context",
  key: "flag",
  true: { template: "on-${0}", items: [{ src: "context", key: "mode" }] },
  false: "off"
}
```

Правила для булевых атрибутов:

- Непустая строка включает атрибут (`disabled`, `readonly`, ...)
- Пустая строка — атрибут не устанавливается

### 3) Условное значение (по выражению)

```ts
class: {
  items: [
    { src: "core", key: "isActive" },
    { src: "context", key: "isActive" }
  ],
  template: "${0}===${1}",
  true: {
    template: "${0}-active-${1}",
    items: [ { src: "context", key: "item" }, { src: "context", key: "status" } ]
  },
  false: "inactive"
}
```

Особенности:

- `template` — строка логического выражения над позиционными значениями `${i}` из `items`
- `items` — источники значений: `state`, `context|core` c `key`, глобальный путь `string[]` с `key?`, `item` с `key?`
- Ветви `true`/`false` — строка или шаблон `{ template, items }`

Оптимизации:

- Если выражение — просто значение одной переменной (эквивалентно `"${0}"`), используйте короткую форму по источнику `{ src, key? }`

### 4) Массивы и вложенные массивы

- Внутри элементов массивов ссылки на `item.*` нормализуются в глобальные пути `src: [root, ..., key]` с применением текущего `arrayContext`
- Для вложенных массивов путь накапливается: `src: ["core","groups","items"]`
- В условных выражениях используйте те же источники в `items`

### 5) Смешанные классы

`class` может быть:

- строкой: `"btn"`
- объектом: условное значение
- массивом: смешанный формат, где элементы — строки и/или условные объекты

Пример:

```ts
class: [
  "btn",
  { src: "context", key: "isLarge", true: "btn-lg", false: "btn-sm" }
]
```

### 6) Примечание

Старый формат `type: "conditional"` не используется.
