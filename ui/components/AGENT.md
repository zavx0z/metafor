# Components Rules

- Компоненты строятся поверх примитивов из `@metafor/elements`.
- Компонент должен расширять, объединять и стилизовать element-примитивы через свой публичный API, а не заново реализовывать то же базовое поведение локально.
- Общая интерактивность: hit-зоны, pointer-состояния, disabled, focus/tooltip wiring и базовый control chrome должны приходить из `@metafor/elements`, если там уже есть подходящий примитив.
- `Button`-компоненты обязаны брать за основу `button` из `@metafor/elements`. Компонентный слой может добавлять иконки, variants, API mapping и стили, но не должен обходить базовый element button для поверхности кнопки и interactions.
