# Гравитация (Gravity)

## Определение

Гравитация — это сила, которая управляет иерархией и порядком атомов в квантовом поле. Она создает структуры, управляет связями и обеспечивает детерминированное упорядочивание квантовых единиц информации.

Гравитация не создает атомы — она работает с уже существующими в Поле, формируя из них иерархические структуры и обеспечивая предсказуемый порядок их взаимодействия.

---

## Сущность и структура

Гравитацию можно представить как силу, которая:

- Управляет `childrenView` — внутренним представлением иерархии атомов
- Генерирует `orderKey` — лексикографические ключи для детерминированного упорядочивания
- Обеспечивает вставку атомов по индекс-путям и между соседями
- Синхронизирует иерархическую структуру с базовой топологией Поля

Гравитация знает о связях между атомами и управляет их иерархией, но не вмешивается в внутреннюю логику самих атомов.

---

## Функции гравитации

В философском ключе гравитация выполняет следующие функции:

1. Архитектор иерархий
   - Создает и поддерживает древовидные структуры из атомов.
   - Обеспечивает предсказуемый порядок дочерних элементов.
2. Генератор порядка
   - Вычисляет лексикографические ключи для детерминированного упорядочивания.
   - Обеспечивает стабильность порядка при вставках и перемещениях.
3. Навигатор по структуре
   - Предоставляет индекс-пути для точного позиционирования атомов.
   - Обеспечивает поиск атомов по их позиции в иерархии.
4. Синхронизатор состояний
   - Поддерживает согласованность между `childrenView` и топологией Поля.
   - Обеспечивает целостность иерархических связей.

---

## Принципы ТКП

1. Силовая природа
   - Гравитация воздействует на атомы, но не изменяет их внутреннюю сущность.
   - Она работает с топологией, предоставляемой Полем.
2. Детерминированность
   - Все операции упорядочивания предсказуемы и воспроизводимы.
   - Порядок атомов стабилен при одинаковых входных данных.
3. Иерархическая ответственность
   - Гравитация управляет только структурными связями между атомами.
   - Она не вмешивается в логику самих атомов или их взаимодействие.
4. Синхронизация с Полем
   - Все изменения иерархии отражаются в топологии Поля.
   - Гравитация работает через доверенные методы Поля.

## Алгоритмы и механизмы

### Генерация orderKey

- Использует лексикографическое сравнение `Uint8Array` ключей
- Функция `between()` вычисляет промежуточные ключи для вставки
- Обеспечивает бесконечную плотность ключей между любыми соседями

### Управление childrenView

- Внутренняя карта `parentId -> childIds[]` для быстрого доступа к детям
- Автоматическая синхронизация с топологией Поля
- Поддержка корневого уровня через специальный ключ `"__ROOT__"`

### Индекс-пути

- Строковое представление позиции: `"0/1/2"` (индексы от корня)
- Двунаправленное преобразование: `getPath()` ↔ `getIdByIndexPath()`
- Валидация путей и обработка ошибок навигации

## Метафора

Если проводить аналогию с физикой:

- Гравитация — это сила притяжения, которая формирует структуры из частиц.
- атомы — это частицы, которые подчиняются гравитационным силам.
- Поле — это пространство, в котором действует гравитация.
- orderKey — это координаты частиц в гравитационном поле.

Гравитация создает из хаоса квантовых частиц упорядоченные структуры, но не изменяет природу самих частиц.

---

## Взаимодействие с другими модулями

- **Поле (Field)**: Гравитация читает и изменяет топологию атомов через доверенные методы
- **атомы (Atoms)**: Гравитация не вмешивается в их внутреннюю логику
- **Внешние системы**: Предоставляет API для навигации и управления иерархией

Гравитация — это мост между статичным Поле и динамичными системами, обеспечивающий структурированное взаимодействие квантовых единиц.
