# Инструкции проекта

Этот файл — путеводитель по правилам проекта. Все специализированные правила находятся в директории `.qwen/rules/`.

---

## ⚠️ Важно: Управление контекстом

**Не читай все правила заранее!** Это засоряет контекст сессии.

**Правильный подход:**

1. **Держи в памяти только этот каталог** — для навигации по правилам
2. **Читай правило только если задача его затрагивает** — по триггерам ниже
3. **Ссылки на другие правила внутри правил** — открывай только после применения текущего правила

---

## 📖 Обязательные правила (прочитать сразу)

Эти правила нужно прочитать **в начале сессии** — они применяются ко всем задачам:

| Правило                     | Зачем                                                          |
| --------------------------- | -------------------------------------------------------------- |
| `.qwen/rules/session.md`    | Работа с историей сессии ("вспомни о...", "что решили по...")  |
| `.qwen/rules/rules.edit.md` | Редактирование правил после ошибок (обновлять контекст сессии) |

**Порядок действий:**

``` text
1. Начало сессии → прочитай session.md, rules.edit.md
2. Держи в памяти процесс работы с историей и обновления правил
3. При запросе "вспомни о..." → следуй процессу из session.md
4. При ошибке в правиле → следуй процессу из rules.edit.md
```

---

## ⚡ Обязательный чек-лист перед действием

**Перед любым действием — проверь триггеры:**

| Действие | Прочитай правило |
|----------|------------------|
| Редактируешь Markdown-файл (`.md`) | `.qwen/rules/markdown.md` |
| Создаёшь новый модуль | `.qwen/rules/module.md` |
| Работаешь с пакетами `@boundary/*`, `@metafor/*` | `.qwen/rules/packages.md` |
| Документируешь код (TSDoc) | `.qwen/rules/tsdoc.md` |
| Пишешь чистые функции | `.qwen/rules/fp.md` |
| Работаешь с графами | `.qwen/rules/graph.md` |
| Создаёшь новый skill | `.qwen/rules/skills.md` |
| Создаёшь новое правило | `.qwen/rules/rules.md` |
| **Редактируешь существующее правило** | **`.qwen/rules/rules.edit.md` (процесс согласования)** |
| Пользователь указал на ошибку после применения правила | **Перечитай правило заново, найди упущенную деталь** |

**Принцип:**

```text
❌ Не действуй по инерции
✅ Сначала прочитай правило → потом действуй
```

## 🔁 Перечитывай перед каждым ответом

**Перед отправкой любого ответа — проверь:**

1. [ ] Прочитал ли я применимое правило из чек-листа?
2. [ ] Запустил ли skill если создавал таблицу? (`table-format`)
3. [ ] Следовал ли процессу согласования если редактировал правило?
4. [ ] Ответ краткий (по умолчанию) или есть запрос на развёрнутый?

**Принцип:**

```text
Не «помню правило» → «открываю и применяю»
```

## 📁 Правила по задачам (читать по необходимости)

Читай эти правила **только если задача их затрагивает**:

| Триггер                                               | Правило                                                                    |
| ----------------------------------------------------- | -------------------------------------------------------------------------- |
| **Вспомни обсуждение из сессии**                      | `.qwen/rules/session.md`                                                   |
| **Markdown (таблицы, списки, код)**                   | `.qwen/rules/markdown.md`                                                  |
| **Создаёшь новый модуль?**                            | `.qwen/rules/module.md` (структура файлов, store-файлы, `.t.ts` для типов) |
| **Работаешь с пакетами `@boundary/*`, `@metafor/*`?** | `.qwen/rules/packages.md`                                                  |
| **Документируешь код (TSDoc)?**                       | `.qwen/rules/tsdoc.md`                                                     |
| **Пишешь чистые функции?**                            | `.qwen/rules/fp.md`                                                        |
| **Работаешь с графами?**                              | `.qwen/rules/graph.md`                                                     |
| **Создаёшь новый skill?**                             | `.qwen/rules/skills.md`                                                    |
| **Создаёшь новое правило?**                           | `.qwen/rules/rules.md`                                                     |

**Пример:**

``` text
Задача: "создай новый модуль"
→ Прочитай module.md
→ Если нужно документировать → прочитай tsdoc.md
→ Если нужны store-файлы → прочитай packages.md (раздел store)
```

## 🛠️ Skills

Skills — инструменты автоматизации рутинных задач (подсознание AI).

**Принцип:** не делай вручную то, что делает skill.

| Skill          | Задача                         | Команда                                              |
| -------------- | ------------------------------ | ---------------------------------------------------- |
| `table-format` | Выравнивание таблиц в Markdown | `bun run .qwen/skills/table-format/format.ts <файл>` |

**Поток:** AI генерирует контент → запускает skill → получает отформатированный результат.

См. `.qwen/rules/skills.md#0-Принцип-подсознания`.

---

## 📘 Документация кода

Вся документация живёт **внутри кода** в формате TSDoc. См. `.qwen/rules/tsdoc.md`.

---

## ⚡ Функциональное программирование

При написании функций следуй принципам чистых функций. См. `.qwen/rules/fp.md`.

---

## 📝 Примечания

**META_RULES.md:** находится в `metafor/create-metafor/rules/` и содержит правила MetaFor DSL — используй его при работе с файлами `meta.ts`.

**Перед генерацией кода:** просканируй соответствующее правило из раздела "Правила по задачам", если задача затрагивает указанную область.
