# Создание Skills

Skills — это автоматизированные инструменты для выполнения специфических задач в Qwen Code.

---

## Принцип подсознания

**Skills выступают в роли подсознания AI-агента.**

### Зачем это нужно

* **Разгрузка контекста:** не требуется описывать в правилах то, что выполняется на подсознательном уровне
* **Экономия токенов:** правила содержат только логику, а не механические действия
* **Фокус на смысле:** AI концентрируется на содержании задачи, а не на форматировании

### Что выносить в skills

| Категория                       | Примеры                               | Почему в skill              |
| ------------------------------- | ------------------------------------- | --------------------------- |
| **Механическое форматирование** | Выравнивание таблиц, отступы, пробелы | Не требует понимания смысла |
| **Автоматическая генерация**    | Шаблоны кода, boilerplate             | Повторяющиеся действия      |
| **Специализированные задачи**   | Парсинг PDF, извлечение данных        | Узкая ответственность       |

### Что оставлять в правилах

| Категория                | Примеры                                    | Почему в правиле            |
| ------------------------ | ------------------------------------------ | --------------------------- |
| **Логика и архитектура** | Структура модулей, потоки данных           | Требует понимания контекста |
| **Best practices**       | Чистые функции, разделение ответственности | Содержательные решения      |
| **Стиль кода**           | Именование, TSDoc, организация             | Связано с семантикой        |

### Пример

**❌ Неправильно (в правиле):**

```markdown
## 1. Таблицы

Выравнивай колонки по ширине:
| Тип       | Где     |
| --------- | ------- |
| Локальное | pkg     |
| Общее     | domain  |

Pipe-символы должны быть выровнены по вертикали.
Пробелы вокруг контента обязательны.
```

**✅ Правильно (в правиле):**

```markdown
## 1. Таблицы

Используй skill `table-format` для форматирования:

``` bash
bun run .qwen/skills/table-format/format.ts <файл>
```

Требования к структуре:

* Разделитель с пробелами: `| --- |`
* Без inline HTML (`<br>`)

**В SKILL.md:**

``` markdown
---
name: table-format
description: Выравнивание колонок таблиц в Markdown.
---

# Table Format Skill

Выравнивает:
1. Колонки по ширине
2. Pipe-символы по вертикали
3. Пробелы вокруг контента
```

### Workflow

```text
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│ Правило         │     │ Skill           │     │ Результат       │
│ (сознание)      │ ──→ │ (подсознание)   │ ──→ │ (автоматически) │
│ Логика, смысл   │     │ Механика, рутина│     │                 │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

**Процесс:**

1. AI генерирует контент по правилу (логика, структура)
2. AI запускает skill для форматирования (механика)
3. Результат готов без ручной работы

---

## Структура skill

```text
.qwen/skills/<skill-name>/
├── SKILL.md           ← Обязательно: документация с YAML frontmatter
├── format.ts          ← Скрипт выполнения (опционально)
├── scripts/           ← Дополнительные скрипты (опционально)
└── templates/         ← Шаблоны файлов (опционально)
```

## Файл SKILL.md

### Обязательный YAML frontmatter

**Формат:**

```markdown
---
name: <skill-name>
description: <краткое описание>
---
```

**Требования:**

| Поле          | Тип    | Требования                                       | Пример                                                                                      |
| ------------- | ------ | ------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| `name`        | string | lowercase, дефисы, без пробелов                  | `table-format`, `pdf-extract`                                                               |
| `description` | string | Непустая строка, что делает + когда использовать | `Форматирование таблиц в Markdown. Использовать при редактировании .md файлов с таблицами.` |

### Структура Markdown

**Обязательные разделы:**

1. **Заголовок** — название skill
2. **Описание** — что делает skill
3. **Использование** — команды для запуска
4. **Примеры** — до/после или вход/выход

**Опциональные разделы:**

* **Правила** — правила работы skill
* **Зависимости** — что требуется для работы
* **Скрипты** — описание вспомогательных скриптов

### Пример SKILL.md

```markdown
---
name: table-format
description: Форматирование ширины колонок таблиц в Markdown файлах согласно QWEN.md. Использовать при редактировании markdown файлов с таблицами для выравнивания колонок и pipe-символов.
---

# Table Format Skill

Форматирование ширины колонок таблиц в Markdown-файлах.

## Описание

Этот skill выравнивает:
1. Колонки таблиц по ширине для читаемости
2. Pipe-символы `|` по вертикали (MD060)
3. Разделители с пробелами (`| --- |`)

## Использование

```bash
bun run .qwen/skills/table-format/format.ts <файл>
```

Или для всех markdown файлов в директории:

```bash
bun run .qwen/skills/table-format/format.ts .
```

### Пример файла

**До:**

```markdown
| Тип       | Где                  | Для чего                             |
| --------- | -------------------- | ------------------------------------ |
| Локальное | `@{pkg}/store.ts`    | Данные для одного пакета             |
| Общее     | `@{domain}/store.ts` | Данные для нескольких пакетов domain |
```

**После:**

```markdown
| Тип       | Где                  | Для чего                             |
| --------- | -------------------- | ------------------------------------ |
| Локальное | `@{pkg}/store.ts`    | Данные для одного пакета             |
| Общее     | `@{domain}/store.ts` | Данные для нескольких пакетов domain |
```

## Зависимости

* Bun runtime
* Нет внешних зависимостей

## Скрипт skill

### Требования

* **Язык:** TypeScript или JavaScript
* **Runtime:** Bun (предпочтительно) или Node.js
* **Зависимости:** Минимум внешних зависимостей
* **Вывод:** Чёткие сообщения об успехе/ошибке

### Структура скрипта

```typescript
#!/usr/bin/env bun

/**
 * <Skill Name>
 *
 * Краткое описание skill.
 *
 * Использование:
 *   bun run .qwen/skills/<name>/<script>.ts <аргументы>
 */

import { readFile, writeFile } from "node:fs/promises"

// Основная логика
async function main(): Promise<void> {
  const args = process.argv.slice(2)
  
  if (args.length === 0) {
    console.log("Использование:")
    console.log("  bun run .qwen/skills/<name>/<script>.ts <аргументы>")
    process.exit(1)
  }
  
  // Логика skill
  console.log(`✅ Выполнено: ${args[0]}`)
}

main()
```

### Пример: table-format/format.ts

```typescript
#!/usr/bin/env bun

/**
 * Table Format Skill
 *
 * Форматирование ширины колонок таблиц в Markdown-файлах.
 *
 * Использование:
 *   bun run .qwen/skills/table-format/format.ts <файл>
 */

import { readFile, writeFile } from "node:fs/promises"

async function processFile(filePath: string): Promise<void> {
  const content = await readFile(filePath, "utf-8")
  
  // Логика форматирования таблиц
  const formatted = formatTables(content)
  
  if (formatted !== content) {
    await writeFile(filePath, formatted, "utf-8")
    console.log(`✅ Отформатирован: ${filePath}`)
  }
}

async function main(): Promise<void> {
  const args = process.argv.slice(2)
  
  if (args.length === 0) {
    console.log("Использование:")
    console.log("  bun run .qwen/skills/table-format/format.ts <файл>")
    process.exit(1)
  }
  
  await processFile(args[0]!)
}

main()
```

## Чек-лист создания skill

Перед публикацией skill проверь:

* [ ] Создана директория `.qwen/skills/<name>/`
* [ ] Файл `SKILL.md` содержит валидный YAML frontmatter
* [ ] Поле `name` — lowercase, дефисы, без пробелов
* [ ] Поле `description` — конкретное описание с триггерами
* [ ] Инструкции чёткие и пошаговые
* [ ] Примеры использования добавлены
* [ ] Скрипт работает автономно
* [ ] Скрипт выводит понятные сообщения
* [ ] Нет внешних зависимостей (или минимум)
* [ ] Skill протестирован на реальных данных

## Best Practices

### Фокусировка

✅ **Узкая ответственность:**

* `table-format` — только форматирование таблиц
* `pdf-extract` — только извлечение текста из PDF

❌ **Слишком широко:**

* `markdown-tools` — всё про Markdown (разделить на несколько skills)
* `document-processor` — обработка документов (разделить по форматам)

### Описание

Включать конкретные триггеры:

```markdown
✅ Правильно:
description: Форматирование ширины колонок таблиц в Markdown.
Использовать при редактировании .md файлов с таблицами.

❌ Неправильно:
description: Инструмент для работы с таблицами.
```

### Автономность

Skill должен работать без дополнительных настроек:

```typescript
✅ Правильно:
// Нет внешних зависимостей
import { readFile } from "node:fs/promises"

❌ Неправильно:
// Требует установки npm пакетов
import { parse } from "markdown-table-parser"
```

### Вывод сообщений

```typescript
✅ Правильно:
console.log(`✅ Отформатирован: ${filePath}`)
console.log(`✓ Без изменений: ${filePath}`)
console.error(`❌ Ошибка: ${error}`)

❌ Неправильно:
console.log("done")
console.log("error")
```

## Тестирование skill

### Ручное тестирование

```bash
# Запустить skill на тестовом файле
bun run .qwen/skills/<name>/<script>.ts test-input.md

# Проверить результат
diff test-input.md test-input.md.orig
```

### Автоматическое тестирование

```typescript
// .qwen/skills/<name>/<name>.spec.ts
import { test, expect } from "bun:test"
import { formatTables } from "./format.ts"

test("выравнивает колонки таблиц", () => {
  const input = "| Тип | Где |\n| --- | --- |\n| Локальное | pkg |\n"
  const expected = "| Тип       | Где     |\n| --------- | ------- |\n| Локальное | pkg     |\n"
  expect(formatTables(input)).toBe(expected)
})
```

## Регистрация skill

Skills автоматически обнаруживаются из директории `.qwen/skills/`.

**Не требуется:**

* `skills.json` — не нужен
* Явная регистрация — не требуется
* Конфигурация — минимальная

**Требуется:**

* Директория `.qwen/skills/<name>/`
* Файл `SKILL.md` с YAML frontmatter
