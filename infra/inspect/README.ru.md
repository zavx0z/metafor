Веб-компонент `meta-inspect` для пошаговой отладки акторов в браузере.

## Что уже работает

- Элемент управления: фиксированная панель с кнопками — «перезагрузка», «пауза/продолжить», «шаг»
- Пауза/возобновление глобальной системы акторов (`Actor.break()` / `Actor.resume()`)
- Пошаговое выполнение следующего сообщения (`Actor.step()`)
- Опциональная остановка на старте через атрибут `brk`
- Индикатор на кнопке показывает ДЕЙСТВИЕ при клике: ▶ (возобновить), ⏸ (поставить на паузу)

## Использование

1. Подключить модуль веб‑компонента (ESM)

   ```html
   <script type="module">
     import "./web/debugger.ts"
   </script>
   ```

2. Вставить компонент на страницу

   ```html
   <!-- стартуем с паузы на первой «строке» (как --inspect-brk) -->
   <meta-inspect brk></meta-inspect>

   <!-- либо без паузы на старте -->
   <meta-inspect></meta-inspect>
   ```

## Атрибуты

- `brk` — при наличии ставит систему на паузу сразу после подключения компонента. Удаление атрибута снимает паузу
