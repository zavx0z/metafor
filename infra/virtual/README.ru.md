# @metafor/virtual

Визуализация виртуальными частицами в процессе инициализации зависимостей графической системы.

## Описание

`@metafor/virtual` предоставляет инструмент для визуализации структуры атомов MetaFor в виде анимированных частиц на canvas. Визуализация выполняется в Web Worker для обеспечения плавной анимации без блокировки основного потока.

## Установка

```bash
bun add @metafor/virtual
```

## Использование

### Базовый пример

```javascript
import { load } from "@metafor/virtual"
import { Atom } from "@metafor/atom"

// Загрузка визуализации
const destroy = await load({
  src: "./dist/worker.js",
  mode: "tree",
  debug: true,
})

// Инициализация атомов
Atom.fromSchema({ meta })

// Очистка ресурсов (опционально)
// destroy()
```

### Параметры

Функция `load` принимает объект с параметрами:

- `src` (обязательный) — путь к worker-файлу для визуализации
- `dst` (опционально) — элемент DOM, в который будет добавлен canvas (по умолчанию `document.body`)
- `mode` (опционально) — режим визуализации: `"tree"`, `"line"` или `"quantum"` (по умолчанию `"tree"`)
- `debug` (опционально) — включить отладочные логи в консоль (по умолчанию `false`)

### Возвращаемое значение

Функция `load` возвращает `Promise<Function>`, который разрешается функцией `destroy` для очистки ресурсов:

- Отписывается от событий `visibilitychange` и `resize`
- Отправляет сообщение `destroy` в worker
- Завершает работу worker

## Интеграция с Atom

Визуализация автоматически отслеживает активные атомы через `Atom.getAllAddresses()` и обновляет отображение частиц при изменении структуры атомов. Пути атомов передаются в worker с дебаунсом (100 мс) для оптимизации производительности.

## Режимы визуализации

- **tree** — древовидная структура с орбитальным расположением частиц
- **line** — линейное расположение частиц
- **quantum** — квантовый режим визуализации

## События

Визуализация автоматически обрабатывает:

- **visibilitychange** — приостанавливает анимацию, когда вкладка скрыта
- **resize** — обновляет размеры canvas при изменении размера окна
