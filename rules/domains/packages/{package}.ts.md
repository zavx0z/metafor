# Оркестратор пакета

Пакетный оркестратор содержит runtime-логику конкретного подпакета.

## Импорты

1. Типы из конкретных subpath пакета `@metafor/types`.
2. Значения из соседних runtime-модулей и доменных пакетов.
3. Локальные относительные импорты.

Типы пакета не объявляются рядом с runtime-кодом. Новый контракт переносится в существующий раздел `@metafor/types/metafor`, `force`, `boundary`, `matrix`, `bulk`, `energy` или `template`.

## Запрещено

- локальные `type` / `interface`
- re-export типов из `index.ts`
