`index.ts` — это публичная граница пакета.

- реэкспортируй только то, что является частью межпакетного API и должно импортироваться из других пакетов;
- если символ нужен только внутри своего пакета, держи его рядом с реализацией и импортируй напрямую;
- не выноси в `index.ts` внутренние helper-функции, промежуточные типы и временные контракты, если они не входят в API пакета;
- если один пакет импортирует символ из другого пакета через `@...`, этот символ должен быть доступен из `index.ts` того пакета, который его предоставляет;
- `index.ts` должен описывать контракт пакета, а не собирать все его внутренние exports.
