# Оркестратор домена

Доменный оркестратор содержит runtime-логику и координирует внутренние пакеты.

## Импорты

1. Типы из `@metafor/types/{section}/{module}`.
2. Значения из доменных пакетов.
3. Локальные runtime-модули.

Типы не объявляются в оркестраторе. Если нужен новый контракт для `dark`, `boundary`, `matrix`, `bulk`, `energy` или корневого MetaFor API, добавь его в подходящий файл `@metafor/types`.

## Запрещено

- локальные `type` / `interface`
- re-export типов из доменного `index.ts`
