# Oркестратор домена, содержит основную логику и координирует работу внутренних пакетов и модулей

## Импорты

### Что импортируется и в каком порядке

> Не обязательно в полном составе перечисленном в списке

1. Типы из `@{domain}/types`
2. Типы из `@{domain}/types/{package}`
3. Чистые функции пакетов @{domain}/{package}
4. Собственный стор `import { store$ } from "./store.ts"`
5. Локальные импорты (относительные пути)

## Типы

### Объявление

- типы модуля объявляются в `@{domain}/types/{domain}.ts` (внутренний)
  > тип который не используется в других модулях
- типы модуля объявляются в `@{domain}/types/shared.ts` (общий)
  > тип который используется в других модулях

## Стор

- нельзя в функциях оркестратора брать собственный стор из аргументов
  > использовать прямой импорт
