# Rules

This directory stores project rules for AI agents.

## Layers

- `governance/` — rules about agent behavior, context use, tools, and rule maintenance
- `engineering/` — rules for writing code and documentation
- `architecture/` — rules for module, package, and graph structure
- `project/` — project-specific rules

## Usage

Start from `../AGENT.md`.
Read only the rule files required by the current task.
