# `@internal/*`

`@internal/*` — пространство сменяемых служебных функций самого Hamiltonian.
Оно позволяет обновлять знакомство, управление, наблюдение и другие внутренние
возможности вместе с выпуском, сохраняя начальную часть минимальной.

Общее назначение Hamiltonian находится в [корневом README](../README.md).
Состав и обновление этих функций принадлежат
[`@hamiltonian/release`](../release/README.md).

## Как устроена внутренняя функция

Имя каждого пакета выражает его функцию. Место работы выбирается отдельно: одна
функция может иметь части для браузера, Service Worker, серверного процесса или
другой среды и при этом остаётся одним пакетом.

Все платформенные части функции принадлежат одной версии пакета. При изменении
одной части выпуск подготавливает согласованный набор частей как одно
обновление.

Когда выпуску нужна внутренняя функция:

1. выпуск выбирает пакет по его назначению;
1. определяет, в каких средах функция должна работать;
1. получает и проверяет согласованные части пакета;
1. запускает каждую часть в подходящей среде;
1. принимает готовность общего результата функции.

Наблюдаемый результат — Hamiltonian получает одну служебную возможность во всех
нужных местах исполнения. Её платформенные части обновляются согласованно и
сохраняют единое назначение независимо от места работы.

## Документы внутренних функций

Этот README закрепляет общий смысл пространства `@internal/*`. Каждый входящий
в него пакет отдельно объясняет собственное назначение, событие запуска,
решение и наблюдаемый результат.

Одна из внутренних функций — [`@internal/visual`](visual/README.md): она
отвечает за визуальную среду Hamiltonian и отображение фактически наблюдаемой
работы.
Точные программные интерфейсы внутренних пакетов принадлежат их открытым типам
и документации исходного кода.
