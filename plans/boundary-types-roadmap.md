## Выявленные проблемы

### 1. Множественные условия для одного поля (PRIORITY: HIGH) ✅ ИСПРАВЛЕНО

**Проблема:** Множественные условия для одного поля работают как OR, а не AND.

```typescript
// Ожидаемое поведение:
{ value: { gte: 10, lte: 20 } } // value >= 10 AND value <= 20

// Текущее поведение:
{ value: { gte: 10, lte: 20 } } // value >= 10 OR value <= 20
```

**Решение:** Исправлено в [`compiler.ts`](boundary/src/compiler.ts). Проблема была в том, что `compileConditions` записывал количество уникальных полей вместо общего количества условий. Шейдер уже имел правильную AND логику, но получал неверное значение `cond_count`.
