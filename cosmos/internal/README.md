# `@internal/*`

`@internal/*` — пространство сменяемых инфраструктурных возможностей Cosmos.
Internal-пакет входит в release, но не является предметным законом Quantum.

Пакет сам владеет:

- своим именем и версией;
- перечнем поддерживаемых environments;
- package-owned typecheck/build;
- публичным API соответствующей возможности.

`@cosmos/release` отвечает только за включение точной версии пакета в
согласованный выпуск, сборку его environments, доставку и обновление.

## Почему это отдельный namespace

`@cosmos/*` содержит механизм существования и обновления самой среды исполнения.
`@internal/*` содержит сменяемые реализации возможностей, которые эта среда
предоставляет загруженному коду.

Граница выглядит так:

```text
@cosmos/startup
      |
      v
@cosmos/release
      |
      +---- @internal/*
      |
      +---- загружаемый MetaFor/Quantum код
```

Quantum не должен становиться владельцем физической реализации internal-пакета.
Для доменного кода предоставленная возможность является частью существующей
среды исполнения.

## Package environments

Environment объявляется conditional export самого пакета. Например:

```json
{
  "exports": {
    ".": {
      "internal:main": "./main/index.ts",
      "internal:server": "./server/index.ts"
    }
  }
}
```

Одна версия пакета охватывает все объявленные environments. Изменение реализации
в любом environment означает новую версию пакета целиком.

## Текущий пакет

Сейчас в этом пространстве находится `@internal/visual`.

Он предоставляет browser visual environment и server environment marker.
Текущая реализация `main` создаёт `UiRuntime` на `#visual-canvas`, добавляет
пространство, display и HUD dock. Это инфраструктурная возможность Cosmos, а не
описание предметных сущностей Quantum.

## Инвариант

Internal-пакет допустим в Cosmos, если его возможность универсальна для выпуска
и не владеет предметным причинным состоянием Quantum. Если функциональность ещё
является экспериментальной или пользовательской, она должна сначала жить на
уровне Quantum, а не автоматически становиться `@internal/*`.
