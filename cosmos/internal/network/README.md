# Сетевое участие устройства

`@internal/network` (далее — network) описывает устройство, которому требуется
только участие в сети. Meta объявляет одного сетевого участника и управляет
его подготовкой, запуском и остановкой. Она не объявляет Capsule или выбор
поведения по операционной системе.

Первое рождение может по явному ordinary input только подготовить private
данные участника. Подтверждённая подготовка не запускает сеть. После штатной
остановки следующее рождение восстанавливает данные и начинает обычное участие.
Порядок подтверждений задаёт сама Meta; физический transport принадлежит
[release](../../release/README.md).
