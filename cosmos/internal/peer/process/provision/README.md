# Подготовка участия в сети

`@internal/network-provision` (далее — provision) переносит назначенную private
конфигурацию в объявленную Mass сетевого участника. Он не создаёт соединений
или живой сетевой объект. Решение подготовить данные принадлежит
[Meta участника](../../README.md).

Process получает точный private inbox как native Energy context. Он проверяет
владельца, права, размер и отсутствие symlink, затем валидирует конфигурацию
через публичный API release. Credential остаётся только приватными bytes.

Успех означает наличие полной устойчивой пары файлов в своей directory Mass
и освобождённый lease. Точный повтор идемпотентен; конфликтующий или неполный
результат остаётся явным отказом. Process не восстанавливает crash prefix
догадками и не объявляет его готовым.
