# Нативное исполнение

`@metafor/repl` (далее — repl) является инструментом Agent для назначенной
владельцем долгоживущей среды Bun. Явный запрос исполняет код с возможностями
ОС; следующие команды используют тот же heap до завершения процесса.
Назначение и секрет доступа принадлежат хосту, а Tool получает закрытые
операции [Oracle Environment](../../docs/domains/ENERGY.md#доступ-process-к-oracle-environment).

Repl сохраняет намерение до внешнего эффекта и возвращает наблюдаемый результат
задания. Повтор завершённого запроса возвращает сохранённую квитанцию. Повтор
незавершённого запроса только наблюдает ранее принятое задание; потерянный heap
или неизвестный исход запрещает автоматически исполнять прежний код снова.
Новая явная задача может открыть новую сессию. Ошибка JavaScript является
результатом инструмента, а потеря транспорта — терминальным отказом запроса.
