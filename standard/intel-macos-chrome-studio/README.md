# Intel macOS Chrome Studio

`intel-macos-chrome-studio` — отдельный корень назначенной локальной Chrome
Studio и стандартного реестра провайдеров. При запуске он подключает сетевого участника и
наблюдение Studio. Открытие, закрытие и сохранение конкретного профиля требуют
явного намерения и исполняются существующим System Agent через публичный API.
Отключение наблюдения сохраняет нативную рабочую сессию.

Сохранение и выбранный шаблон остаются ссылками конфигурации. Корень не читает
cookies, не копирует авторизацию и не присваивает существующий браузер.
[Первое создание мира](../../docs/ENVIRONMENTS.md#развёртывание)
сохраняет отдельную identity, а импорт Mass требует явного протокола.
Agent подключается по явному разрешению владельца; обнаружение провайдеров не вызывает модель.

Вход и управление человеком проходят через WebRTC в принимающем Agent Display.
Meta передаёт привязку существующей сессии; установка самого Studio-сервиса и
его нативный lifecycle остаются у владельца Chrome Studio. Этот корень использует
назначенный работающий сервис и не запускает дополнительный server или UI shell.

Ведущий сетевой участник подтверждает назначенный Oracle-канал отдельно от
ответа Studio. Без этого подтверждения корень остаётся в ожидании Oracle;
готовность HTTP-сервиса не объявляет готовность связанной Вселенной.

Корень хранит единый реестр Provider в своей Mass. Его Provider-владелец
обновляет этот реестр, а явно подключённый Agent и его Chat используют ту же
привязку без отдельной копии настроек. Начальное разрешение Agent выключено.
Основной Agent и два browser Agent имеют независимые разрешения, задачи
и привязки Provider. Каждый дополнительный слот создаёт собственную беседу и
сохраняет историю и native session уже подключённых Agent. Все слоты изначально
выключены; локальный browser Agent получает Provider только после явного выбора.
