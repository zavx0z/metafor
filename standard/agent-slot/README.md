# Подключение агента

Слот сохраняет явное намерение подключить Agent к Atom окружения. Конечный
автомат переводит его в состояние подключения; Matter создаёт Agent только
в этом состоянии. Сам слот не обращается к модели и не исполняет её задачи.

Слот передаёт настройки, значения и ссылку на общий реестр Provider следующему
владельцу. Созданный [Agent](../agent/README.md) владеет собственной беседой и
исполнением; [окружение](../../docs/ENVIRONMENTS.md) продолжает работу независимо
от наличия подключённых агентов.
