# Назначенный Codespace

`@metafor/codespace` (далее — codespace) представляет инструмент наблюдения и
запуска одного существующего Codespace, назначенного владельцем хоста.
Его [автономный Process](../../docs/domains/ENERGY.md) исполняется по явному
запросу без участия модели. Назначение определяет аккаунт и ресурс; запрос
пользователя выбирает только наблюдение либо запуск.

Наблюдение возвращает текущее состояние назначенного ресурса. Запуск передаёт
одно намерение внешнему владельцу и сохраняет квитанцию. Принятие запуска и
готовность Codespace являются разными результатами; готовность VPN, браузера и
провайдера устанавливают соответствующие владельцы.

Сохранённый результат повторного запроса возвращается без нового внешнего
действия. Перед запуском codespace сохраняет намерение. Если завершение осталось
неизвестным, повторный запуск автоматически не выполняется; наблюдение остаётся
доступным для проверки состояния. Изменение операции при прежней identity
запроса отклоняется. Явный новый запрос владельца может начать новое действие.

Хост выдаёт [Oracle Environment](../../docs/domains/ENERGY.md#доступ-process-к-oracle-environment)
только инструменту с точной Meta identity. Инструмент получает закрытые операции,
а учётные данные и способ обращения к внешней системе остаются у хоста.
Несовпадение назначенного аккаунта, отсутствие ресурса или неопределённый исход
обращения являются ошибкой; другой аккаунт и создание ресурса не подставляются.
