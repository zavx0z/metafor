# Рабочее окружение

`@metafor/environment` (далее — environment) связывает задачу, специалиста,
его беседу и инструмент проверки в одной агентной Вселенной. Сообщение или задача
становится обычным Field конкретного Atom; состояние и ответ изменяются только
после причинного исполнения участников.

Обычное сообщение получает свободный ответ выбранного Agent. Явный запуск сценария
использует его инструмент и возвращает ответ по подтверждённому результату.
Окружение передаёт оба намерения тому же участнику; его беседа сохраняет их историю.

Завершающая декларация `agents` задаёт специалиста, его объявленные инструменты
и источники представлений. Она материализует стандартный Agent через Matter.
Agent сохраняет собственную identity и автоматически получает отдельный Chat.
World и activity Displays описывают наблюдение этого же окружения. Объявление
инструмента не выдаёт право и не заменяет его исполнителя.

Правила [агентной композиции](../../docs/AGENT_UNIVERSES.md#минимальная-стандартная-композиция)
сохраняют исполнение и историю у соответствующих Atom. Cosmos предоставляет
подготовленный код и native-возможности; [исполнение и авторинг](../../docs/META_PACKAGES.md#исполнение-и-авторинг)
сохраняют отдельные права и жизненные циклы.
