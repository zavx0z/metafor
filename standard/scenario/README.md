# Исполнитель сценария

`@metafor/scenario` (далее — scenario) проверяет объявленное свойство мира и
сохраняет результат. Новый запрос переводит Atom в исполнение; Process читает
свой Oracle Environment, выполняет проверку и записывает отчёт в Mass. Boundary
подтверждает итог исполнения обычным причинным путём.

Первый сценарий проверяет согласованность публичного Graph агентной системы,
наличие её участников и объявленного хранения. Он наблюдает настоящий текущий
мир. Каждая проверка имеет отдельный результат; общий успех требует успеха всех
проверок.

Повтор завершённого запроса возвращает сохранённый отчёт. Чтение прерванного
сценария можно выполнить снова: оно не создаёт внешних эффектов. Результаты
сохраняются в Mass при завершении Process и переживают полное восстановление
мира по [общему закону исполнения](../../docs/META_PACKAGES.md#исполнение-и-авторинг).
