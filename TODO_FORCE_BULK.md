# TODO: первый Force → Dark → Bulk этап

Статус: временная рабочая запись. Не является отдельной концепцией.

## Зафиксированное направление

- Force — распределённая причинность, а не только центральный transport.
- Центральный Force связывает локальные силы доменов и является единственным
  внешним ingress.
- Particle остаётся минимальной: `part`, `op`, `path`, optional `value/from`,
  обязательные `by` и `ts`.
- Отдельные causal parent и trace metadata не вводятся.
- Домен получает только релевантную ему Particle и живёт в своём локальном
  времени.
- Bulk выводит проявление из минимального Impulse, состояния, времени, законов и
  Viewpoint.
- Bulk не хранит историю и не получает отдельный trace stream.
- CPU готовит минимальный diff, активное проявление находится на GPU, рендер
  выполняется по запросу.
- Логи остаются независимой технической проверкой transport boundaries.

## Первый минимальный результат

Провести один `inflaton/add` по причинному пути:

```text
agent → central Force → Dark → central Force → Boundary
                                      ↘ Bulk manifestation for Viewpoint
```

Boundary не должен получить raw agent Particle. Bulk должен проявить
относящийся к текущему Viewpoint путь без отдельного trace envelope.

## Definition of done

- runtime принимает только Particle с валидными `by` и `ts`;
- внешний payload не может сам назначить доверенный `by`;
- raw agent Inflaton получает только Dark;
- Dark сохраняет исходный `ts` и испускает `by: dark`;
- Boundary никогда не получает raw agent Inflaton;
- Bulk проявляет путь из обычных минимальных Impulse;
- в Bulk нет отдельного trace store и долговременного replay;
- при покое нет постоянной перерисовки;
- автоматические тесты подтверждают доставку и отсутствие лишних получателей;
- живой сценарий виден для текущего Viewpoint без обязательного чтения логов.
