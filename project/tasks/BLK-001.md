# BLK-001 — Поверхность выбранного объекта

## Зачем

Ввод через общий HUD не доказывает отдельный режим работы с поверхностью
выбранного объекта.

## Открытые вопросы

* Какие действия принадлежат поверхности.
* Как сохраняется выбранный объект при движении сцены.
* Как пользователь возвращается к общему обзору.

## Критерии готовности

Рабочий браузерный путь подтверждён снимком и фактическим изменением выбранного
объекта, сохранёнными в `artifacts/BLK-001/`.
