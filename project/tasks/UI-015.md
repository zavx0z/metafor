# UI-015 — Перевести весь UI на форму и композицию Blender

## Коротко

Elements, Components, Fields и Workbench получают один Blender 4.5.5 visual
system: composition, shape, density, palette и material states. MetaFor
сохраняет project font; группировка и расположение становятся
Blender-подобными во всём UI, а не только в Node Editor.

## Решение владельца

1. Node UI уже показывает правильное направление и остаётся действующим
   эталоном интеграции universal Fields.
2. Весь остальной UI движется к Blender по составу, форме, плотности,
   группировке и положению частей.
3. Новое решение владельца от 2026-08-20 отменяет прежнее сохранение MetaFor
   palette: base colors/material states берутся из Blender 4.5.5. Project font
   остаётся MetaFor; semantic type/status colors требуют явного Blender-role
   mapping.
4. Заранее разрешены ровно два divergence: project font и ортогональная route
   geometry Links. Switcher, округлённая Node header и прочие прежние отличия
   больше не защищены. Link material/states/attachment/interaction следуют
   Blender.
5. Каждый срез сравнивается визуально с exact Blender reference; зелёный test
   без сопоставимого screenshot не доказывает visual parity.

Permanent law: commit `8019ea2de` обновил Elements, Components и shared
Workbench REQUIREMENTS до начала production patch.

#### UI-015.5.2 — Выровнять Vector/Rotation values, единицы и Socket row

Статус и исполнитель: `COMPLETE` на source/stable static live gate; commit
`859973c95`, pointer/keyboard/owner acceptance остаётся parent gate.

Owner RED `components-rotation-alignment-red.png` и exact reference
`node-types_FunctionNodeInputRotation.webp` показали composition drift:
Rotation формирует axes `X°/Y°/Z°`, а numeric text `0/45/90` начинается у левого
padding value-area. Blender использует axes `X/Y/Z` и values `0°/45°/90°`,
выровненные по общей правой кромке.

Shared Vector RED `components-vector-alignment-red.png` показывает тот же
numeric-origin defect: axes pinned к group left, values `1/2/3` начинаются сразу
после axis slot. Exact `FunctionNodeInputVector.webp` требует stable centered
axis column и shared right edge; plain Vector default format — три decimals
`1.000/2.000/3.000`.

Generic numeric text alignment принадлежит Elements Input/NumberInput: right
origin задаёт text, caret, selection и pointer index одной системой. Rotation
только сохраняет default axes и задаёт unit `°`, если explicit field.unit не
передан; Vector default precision `3`, Rotation default precision `0`, explicit
precision/unit (включая empty unit) сильнее. Vector/Matrix не копируют alignment
logic. Axis text использует
source-backed number text role, disabled alpha проходит resolver, hardcoded
`muted` запрещён.

Control layout: narrow axis slot, shared right-aligned value column и consistent
left/right padding. Regular/compact используют одну composition. Node не
растягивает intrinsic Rotation group на весь body без exact ratio proof;
side-by-side фиксирует control/body width и margins.

Socket placement доказан четырьмя exact 4.5 references: GeometryNodeTransform,
FunctionNodeCombineTransform, FunctionNodeRotationToQuaternion и output
FunctionNodeInputRotation. Socket-backed Rotation имеет отдельную верхнюю label
row `Rotation:`; input Socket центрируется на её left boundary, output — на
right boundary. X/Y/Z editor начинается ниже и не владеет Socket Y.
`node_update_basis_socket` сначала фиксирует endpoint на socket label row и
только затем уменьшает `locy` на multi-row editor height.

MetaFor anchor: label row `22`, center `fieldTop + 11`; editor начинается после
label row/group gap. Linked/hide-value может скрыть editor, но сохраняет socket/
label anchor. Regression отдельно покрывает input, output и linked/hidden state;
shape capability не меняет Y law.

Regression: unit attaches to value; explicit unit wins; axis labels/contrast;
Vector precision3/Rotation precision0; right-aligned text/caret/selection/
pointer index; side step/scrub/text editing
остаются source-exact; regular/compact and Node share public control. Live gate:
`X 0° / Y 45° / Z 90°`, same route/target/DPR, keyboard/pointer, console `0`,
Blender side-by-side и owner verdict.

Основание: это новый numeric-alignment/unit/intrinsic-width mechanism, найденный
после UI-015.7.3 live correction; он не смешивается с hierarchy/Select work.

Stable result: Components PID `31534`, target `D0775…`, Vector route показывает
X/Y/Z + right `1.000/2.000/3.000`; Node PID `31535`, target `809…`, Rotation
показывает отдельную `Вращение` label row, Socket на её center и editor ниже с
