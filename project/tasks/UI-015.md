# UI-015 — Перевести весь UI на форму и композицию Blender

## Коротко

Elements, Components, Fields и Workbench получают один Blender 4.5.5 shape
system. MetaFor сохраняет palette, tone colors и project font; размеры, формы,
группировка и расположение становятся Blender-подобными во всём UI, а не только
в Node Editor.

## Решение владельца

1. Node UI уже показывает правильное направление и остаётся действующим
   эталоном интеграции universal Fields.
2. Весь остальной UI движется к Blender по составу, форме, плотности,
   группировке и положению частей.
3. Цветовая схема и project font остаются MetaFor.
4. Прежние явные divergence сохраняются: Switcher, округлённая Node header и
   ортогональные Links.
5. Каждый срез сравнивается визуально с exact Blender reference; зелёный test
   без сопоставимого screenshot не доказывает visual parity.

Permanent law: commit `8019ea2de` обновил Elements, Components и shared
Workbench REQUIREMENTS до начала production patch.

swatch/actions. Node compact Fields уже существенно ближе к reference.

## Подзадачи

### UI-015.1 — Измерить reference и ввести shared shape metrics

Статус и исполнитель: `COMPLETE`, внутренний исполнитель текущей задачи.

Измерить representative controls при сопоставимом масштабе и создать одному
Elements owner shared visible geometry metrics: control/row height, radius,
border, gap, separator, icon slot, compact font и panel/header rhythm. Имена
остаются project-generic; Blender является provenance, не runtime dependency.

Срез не меняет существующие consumers. Regression фиксирует immutable tokens,
взаимные ограничения и отсутствие дублирующих literal shape policies в новом
коде. Measurement note отделяет exact screenshot evidence от выбранного MetaFor
mapping. Package tests/typecheck/build и diff-check проходят.

Подготовительный commit: этот project checkpoint, до production patch.

Результат: commit `af5ae43a8` добавил public immutable `uiShapeMetrics` одному
Elements owner: control `22`, row/header `24`, low radius `3`, border/separator
`1`, tight gap `3`, icon/action slot `22`, compact font `11`. Source comment
сохраняет exact image dimensions/spans отдельно от выбранного local mapping.

Exact measurements: scalar control `146×23`, enum `144×22/23`, vector joined
rows `23/23/24`, path rows `23/22` + action `24`, collection row `121×22` +
action `26`, color value bar `144×22`; screenshot sizes/scales различаются.
Mapping сохраняет уже проверенный Node compact rhythm, а не объявляет pixels
равными local units.

Проверки: Elements `72/72` (`518` assertions), delivery `15/15` (`461`),
package/playground typechecks, browser ESM build и diff-check зелёные.

### UI-015.2 — Перевести базовые Elements primitives

Статус и исполнитель: `COMPLETE` на package/story/live contract; owner visual
acceptance остаётся parent gate.

Elements Input/Button и shared control radius/font/padding используют
`uiShapeMetrics`: low-radius controls, dense text и hit-target/visible-geometry
split. Generic Div, List и Components Pane не меняются в этом первом consumer
slice; они переходят в следующих subtask вместе со своими composition owners.
Package-owned primitive stories получают equal-scale defaults. Palette,
retained lifecycle и public interaction contracts не меняются.

Production prerequisite: `af5ae43a8`. Preparation commit: этот state
checkpoint, до Elements/story patch.

Результат: commit `e6f7669bf` подключил Input/Button к shared metrics через
internal visible-chrome planner. Default chrome центрируется внутри caller hit
rect как `22h`, radius `3`, border `1`, font `11`, horizontal padding `6`;
explicit height/radius/border/font/padding/background остаются сильнее. Hit rect,
callbacks, retained key lifecycle, palette, Div/List/Components не менялись.

Primitive stories теперь показывают equal-scale `146×22`. Elements `76/76`
(`538` assertions), package/playground typechecks, lazy browser build и
diff-check зелёные; independent focused rerun `10/10` (`33`) прошёл.

Live before/after на exact route `input/state/inactive`: PID `64668` → `66578`,
target сохранён, console `0`. Baseline `460×50`, radius28, `543162` bytes;
after `146×22`, radius3, `495019` bytes. Captures и SHA:
[`elements-input-before.png`](../artifacts/UI-015/elements-input-before.png) и
[`elements-input-after.png`](../artifacts/UI-015/elements-input-after.png).
Palette неизменна; Workbench shell ещё намеренно старый.

### UI-015.3 — Перевести scalar Components и Field rows

Статус и исполнитель: `COMPLETE` на source/shape contract; live interaction
выявил отдельный UI-015.4 correction.

Text/Number/Enum/Path/Reference/Boolean/Color scalar controls и regular Field
composition используют ту же silhouette, что Node compact Fields. Regular не
создаёт pills или oversized stacked label/control без reference.

Production prerequisite: `e6f7669bf`. Подготовительный commit: этот state
checkpoint, до Components patch.

Результат: commit `813f48994` перенёс input-like chrome и Button content layout
к Elements owner, добавил public exact `@ui/elements/select`, свёл regular и
compact scalar Field к одной dense row и перевёл package stories на equal-scale
`146`-unit controls. Elements `83/83`, Components `80/80`, delivery `15/15` и
четыре typecheck зелёные.

Live после restart подтвердил scalar/enum форму и console `0`, но owner выявил
новое функциональное расхождение: click закрытого select сохраняет старый cycle
и не раскрывает список. Автоматический кадр доказывает только закрытую форму и
не является acceptance интерактивного select.

### UI-015.4 — Добавить раскрывающееся меню Elements select

Статус и исполнитель: `IN_PROGRESS`, внутренний исполнитель текущей задачи.

`@ui/elements/select` владеет generic options, открытым overlay-списком,
hover/disabled rows, закрытием после выбора и точной caller hit geometry.
`EnumInput` передаёт stable options/value и получает controlled selection,
не рисуя собственное popup menu. Закрытая и раскрытая формы сравниваются с
`node-types_GeometryNodeMenuSwitch.webp`; palette/font остаются MetaFor.
Тот же live review подтвердил слишком яркий idle outline: Elements input,
select и button используют тонкий малоконтрастный project border material, а
cyan остаётся только hover/active/focus. Workbench chrome не получает локальных
обходов и отдельно переходит в UI-015.6.

Preparation commit: этот project checkpoint, до correction patch.

## Границы

* Не менять palette, syntax colors, project font или semantic tone meanings.
* Не копировать Blender source/assets в production MetaFor.
* Не менять callback/value contracts ради формы без отдельной подзадачи.
* Не разрушать retained ownership, FlexBox или package boundaries.
* Node visual exceptions и уже принятые topology laws сохраняются.
