# MF-203 — Утвердить журнал структурной операции

## Зачем

После записи source и последующих фаз должен существовать точный наблюдаемый
исход, а не вывод по косвенным признакам.

## Решение владельца

Нужно определить:

* формат журнала;
* владельца хранения;
* срок удержания;
* связь с checkpoint и history;
* обязательные состояния частичного отказа.

## Критерии готовности

По журналу можно однозначно определить выполненную фазу, результат и допустимый
следующий шаг.
