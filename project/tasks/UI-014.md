# UI-014 — Проверять encoded WebGPU PNG в canvas guard

## Коротко

`$ui-dev canvas` проверяет пиксели того же PNG, который собирается записать, а
не пытается читать hidden WebGPU canvas через ненадёжный direct 2D drawImage.

## История и новое evidence

UI-013 закрыла session recovery и black guard. После closing текущий hidden
Components target дал противоречие: exact raw `canvas.toDataURL("image/png")`
имеет длину `866190` и ранее сохранялся как non-black PNG, но direct
`drawImage(WebGPU canvas → 2D probe)` вернул `nonBlackPixels:0`. Поэтому guard
ложно отклонил содержательный encoded canvas даже после bounded retry.

Это новая подтверждённая причина после закрытия UI-013, не повтор её прежнего
patch. AI-macos использовался только для exact diagnosis по прямому указанию
владельца; permanent browser workflow остаётся `$ui-dev` background-only.
