# UI-014 — Проверять encoded WebGPU PNG в canvas guard

## Коротко

`$ui-dev canvas` проверяет пиксели того же PNG, который собирается записать, а
не пытается читать hidden WebGPU canvas через ненадёжный direct 2D drawImage.

## История и новое evidence

UI-013 закрыла session recovery и black guard. После closing текущий hidden
Components target дал противоречие: exact raw `canvas.toDataURL("image/png")`
имеет длину `866190` и ранее сохранялся как non-black PNG, но direct
`drawImage(WebGPU canvas → 2D probe)` вернул `nonBlackPixels:0`. Поэтому guard
ложно отклонил содержательный encoded canvas даже после bounded retry.

Это новая подтверждённая причина после закрытия UI-013, не повтор её прежнего
patch. AI-macos использовался только для exact diagnosis по прямому указанию
владельца; permanent browser workflow остаётся `$ui-dev` background-only.

## UI-014.1 — Декодировать PNG перед pixel probe

Статус и исполнитель: `IN_PROGRESS`, внутренний исполнитель текущей задачи.

Требование: browser helper сначала получает exact `toDataURL`, затем декодирует
этот PNG в bounded 2D probe через browser-native ImageBitmap/Blob path и
классифицирует видимые RGBA уже encoded artifact. Direct drawImage исходного
WebGPU canvas запрещён. Atomic write, one retry, typed second-black refusal и
viewports/native restore сохраняются.

Граница: только `$ui-dev` browser/helper/tests/reference. Lifecycle dispatcher,
registry, package servers, production UI, project playground и ai-macos source
не меняются.

Regression: source использует encoded PNG decode; transparent RGB остаётся
black, non-black encoded snapshot принимается, black не пишется, existing
destination сохраняется. Browser bundle/typecheck, combined skill tests,
quick_validate и diff-check зелёные.

Live acceptance: на current hidden target `D077…72D2` только `$ui-dev canvas`
без focus/ai-macos должен вернуть non-black probe и atomically update current
UI-010 artifact. Если encoded PNG сам black — guard остаётся typed refusal.

Подготовительный commit: этот project checkpoint, до skill patch.
