# AUD-008 — Утвердить версионные переходы схемы Boundary

## Зачем

Открытие старой или неизвестной базы не должно угадывать её смысл и удалять
канонические данные без утверждённого пути.

## Подтверждённые факты

Boundary определяет старую схему по составу колонок. Явной версии через
`PRAGMA user_version` и полного маршрута перехода нет.

## Решение владельца

* Либо Boundary отказывается открывать неизвестную старую схему.
* Либо каждая поддерживаемая версия получает последовательный переход с
  доказанной резервной копией и проверкой результата.

## Критерии готовности

* Версия хранится явно.
* Проверены текущая, поддерживаемая старая и неизвестная версии.
* Ручной `bun run boundary:backup` остаётся обязательным перед изменением
  схемы или кода перехода.
