# BND-001 — Приватный WIMP-клон для одного Atom

## Зачем

Один Atom должен получить изменяемый WIMP, не меняя остальные Atom общего
исходного WIMP.

## Обсуждаемый вариант

* Отдельная операция fork, а не маскировка под Atom `replace`.
* Новый уникальный `src` и явный `baseSrc`.
* Сохранение identity, values и State выбранного Atom.
* Единый restart scope для Matrix и Energy.
* Copy-on-write неизменённых деклараций.
* Восстановление клона и владельца после холодного запуска.

## Критерии готовности

Из двух Browser Atom только выбранный переключается на новый WIMP, а второй не
меняется.
