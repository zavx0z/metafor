# MF-301 — Реализовать Create через общий структурный путь

## Зачем

Создание новой Meta и изменение существующей не должны иметь разные законы
проверки, записи и материализации.

## Границы

```text
template -> validate -> target patch -> validate -> materialize
```

## Критерии готовности

Create проходит общий структурный договор и не обходит capability, журнал,
проверку revision и наблюдение результата.
