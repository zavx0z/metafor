# MF-409 — Завершить RPC редактирования Matter tree

## Зачем

Первый `meta.matter.apply` доказывает только inert root-level WIMP в последней
позиции и не является полной поверхностью композиции Atom.

## Зависимость

`MF-206` доказывает общий structural live-first/source projection path для
декларационных изменений.

## Границы

* Расширить существующий `meta.matter.apply`, не создавать второй Matter RPC.
* Ввести публичный locator точного occurrence внутри Matter tree без раскрытия
  Boundary row ID.
* Поддержать WIMP, fuzzy, axion и macho, их bindings и значимую sibling
  position.
* Поддержать `add`, `move` и `remove`, включая вложенное occurrence и
  сохранение runtime identity при move.
* Каждая реально изменённая Matter entity остаётся одной accepted Particle.
* Новая access policy, concurrency, copy repository и удаление peer Meta не
  входят.

## Критерии готовности

Один доверенный агент собирает и перестраивает полное Matter tree через
существующее имя RPC, а source, Boundary, Graph и Bulk показывают один и тот же
принятый результат.
