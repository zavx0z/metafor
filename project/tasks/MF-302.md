# MF-302 — Доказать единый договор Create и update

## Зачем

Общий путь должен быть подтверждён не сходством кода, а одинаковыми законами и
наблюдаемыми отказами.

## Критерии готовности

Create и update используют одинаковые:

* capability;
* журнал;
* фазы отказа;
* повтор и согласование;
* решение владельца для canonical commit.
