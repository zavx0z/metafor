# MF-205 — Добавить повтор и согласование после частичной ошибки

## Зачем

Сбой после записи source не должен оставлять неизвестное состояние или
провоцировать новый независимый запуск.

## Границы

* Различать фазу отказа.
* Безопасно повторять только повторяемые действия.
* Согласовывать фактический source и живой результат.
* Не выдавать source write за завершённую операцию.

## Критерии готовности

Для каждого сбоя определён безопасный повтор, согласование или окончательный
отказ с наблюдаемым исходом.
