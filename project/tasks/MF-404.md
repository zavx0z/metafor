# MF-404 — Добавить генератор и обновление Process

## Зачем

Process должен создаваться и изменяться через общий структурный договор, а не
через отдельный неуправляемый генератор.

## Открытые вопросы

Точный договор ещё не сформирован. Его можно обсуждать только после
доказательства единого пути Create и update.

## Границы

Не добавлять Process generator, hot reload или restart в ранний structural
slice.
