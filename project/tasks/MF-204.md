# MF-204 — Материализовать через обычный путь MetaFor

## Зачем

Успешная запись source не доказывает, что изменение стало частью живого мира.

## Границы

* Обычная нормализация.
* Round-trip исходника.
* Действующий путь materialization.
* Фактическое наблюдение результата.
* Никакой частичной горячей перезагрузки доменов.

## Критерии готовности

Операция различает запись source, материализацию и наблюдение, а журнал хранит
точный исход каждой фазы.
