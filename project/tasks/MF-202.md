# MF-202 — Реализовать атомарную запись source

## Зачем

Запись предложения не должна частично заменять исходник или молча перетирать
другую revision.

## Границы

* Точный целевой файл.
* Проверка ожидаемой revision.
* Временный файл и атомарное переименование.
* Повторное чтение записанного результата.

## Критерии готовности

Ошибка любой фазы сохраняет прежний source, а конкурирующее изменение
обнаруживается до замены.
