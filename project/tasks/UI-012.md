# UI-012 — Добавить мягкую производительную SDF-тень

## Коротко

Любой rounded UI component получает ровную мягкую тень со всех четырёх сторон
без дорогого размытия текстуры. Node сможет использовать ту же тень как
нейтральную глубину и как цветное выделение.

## Зачем

Сейчас общего shadow primitive нет. Blender-like Node имитирует тень вторым
смещённым rounded rect, поэтому она видна главным образом справа и снизу и не
похожа на мягкий объём. Несколько полос или texture blur исправили бы картинку,
но добавили бы лишние draws, framebuffer lifecycle и transform-specific работу.

## Связь с дорожной картой

Задача принадлежит общему Engine/Elements presentation layer. NODES-017.8.5
становится её consumer, но не владельцем shader/material contract.

## Связанные задачи и история

* Commit `2ec5884e8` создал `RoundedRectMaterial` с SDF-AA; commit `394bb4bf2`
  перевёл rounded UI drawing на этот material.
* NODES-017 зафиксировала owner law: тень Node симметрична со всех сторон,
  обычная нейтральна, selected получает оттенок header вместо другого border.
* Blender 4.5 source `node_draw_shadow` использует rounded drop shadow шириной
  `0.6 × U.widget_unit`, alpha `0.5` и все corner; это constraint пропорции, а
  не код или asset для копирования.
* Audit текущего Engine/Elements не нашёл shadow material/API. Свободные params
  существующего rounded uniform позволяют аналитический shadow branch без
  второго pipeline layout и без texture resources.

## Решения владельца

1. Тень должна быть визуально мягкой и симметричной со всех четырёх сторон.
2. Реализация должна быть производительной: один SDF quad/draw, без texture
   blur, offscreen framebuffer, post-processing и набора отдельных полос.
3. Blur/spread задаются в local units и наследуют retained parent transform;
   pan/zoom не вызывает rematerialization либо пересборку тени.
4. Primitive остаётся универсальным. Node selection передаёт header-derived
   color снаружи; Engine/Elements не знают selection и Node vocabulary.
5. Пропорции проверяются по exact Blender 4.5.5 reference, но material/theme
   остаются MetaFor.

## Подзадачи

### UI-012.1 — Добавить rounded shadow material и UiSurface primitive

Статус и исполнитель: `IN_PROGRESS`, внутренний исполнитель текущей задачи.

Классификация: первый и единственный production mechanism parent. Он добавляет
общий analytical shadow path; Node consumption остаётся NODES-017.8.5.

Требование: Engine rounded material принимает shadow blur/spread, а
`UiSurface.drawRoundedShadow()` создаёт один симметрично расширенный quad с
local shape size/radii, color, opacity и z.

Причина: current rounded shader отбрасывает fragments вне exact PlaneGeometry,
а Node offset rect имеет hard edge. Для мягкого halo plane должен включать fade
area, при этом SDF продолжает измерять исходный inner rounded rect.

Разрешённое изменение одного механизма: расширить существующие rounded material
params/shader/uniform write и добавить один low-level Surface draw API. Обычный
`drawRoundedRect` output и uniform layout сохраняются; Node renderer не меняется.

Regression: ordinary rounded rect остаётся parameter-equivalent; shadow quad
bounds симметрично равны `spread + blur`, shader path использует один
material/draw, per-corner radii/clip работают, zero/invalid values bounded.
Retained transform меняет world matrix без повторной materialization.

Среда и приёмка: Engine/UI focused tests, shader contract/build, Elements
typecheck и небольшой standalone visual fixture только если UI-011 предоставит
существующий route. GPU/profile evidence сравнивает одинаковый workload и не
подменяет owner visual acceptance.

Подготовительный commit: записывается до implementation patch.

## Границы

* Не добавлять Node/selection/theme policy в Engine или Elements.
* Не менять Node renderer, playground, layout solver или Hamiltonian.
* Не добавлять texture, render target, blur pass, runtime loop или Inspector
  source в production.
* Не вводить screen-space minimum для visible shadow.
* Не создавать второй scene graph или shadow cache с отдельным lifecycle.

## Критерии готовности

1. Public Surface primitive рисует мягкую rounded shadow одним quad/draw.
2. Fade симметричен по четырём сторонам и per-corner radius не ломается.
3. Existing rounded rect tests/output не меняются.
4. Retained transform-only path не увеличивает layout/materialization counters.
5. Engine/Elements typechecks и focused shader/material tests проходят.
6. NODES-017.8.5 может применить primitive без собственного blur/shader code.

## Состояние

`IN_PROGRESS`: UI-012.1 создаёт общий Engine/Elements SDF shadow primitive.
Node integration остаётся отдельным следующим срезом NODES-017.8.5.
