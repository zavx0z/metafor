# MF-402 — Утвердить полную модель управления версиями

## Зачем

Начальный Git и первый commit от Create MetaFor не определяют жизненный цикл
ветвей и публикации результата.

## Решение владельца

Нужно определить:

* branches;
* merge;
* rollback;
* promotion;
* push.

## Критерии готовности

Каждая операция имеет capability, область, проверяемую revision, исход отказа и
отдельное право публикации.
