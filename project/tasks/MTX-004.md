# MTX-004 — Определить исход отсутствующего или зависшего Energy

## Зачем

Один Atom не должен оставаться заблокированным навсегда без описанного
канонического исхода.

## Подтверждённые факты

Риск подтверждён для двух случаев: ни один Energy не принимает Photon либо
принятое выполнение никогда не завершается. Остальная Matrix продолжает
работать.

## Решение владельца

Нужно определить:

* срок ожидания первого Energy;
* срок выполнения принятого Process;
* исход превышения срока: ошибка, повтор, смена State или ручное решение;
* способ снять блокировку только через Boundary.

## Границы

Ранее предположенные случаи замены ожидания, потери разрешения и неизвестного
Photon сначала требуют отдельного воспроизведения и пока не считаются причиной.
