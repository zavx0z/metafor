# LAD-003 — Ответ Лады через Send Tool

## Зачем

Текущий Model Service создаёт `replyDraft`, но Agent не превращает его в
намерение `outgoingMessage`, поэтому готовый Chat Send Tool не запускается.

## Решение владельца

Ответ на принятое явное `@lada` автоматически отправляется один раз в ту же
общую комнату.

## Границы

* Agent не вызывает Chat API напрямую.
* Model Service только создаёт ответ; отправляет существующий Chat Send Tool.
* Ответ причинно связан с исходным `messageKey`.
* Persona передаётся модели как `system` message; reasoning trace не хранится.

## Критерии готовности

* Один принятый inbox message создаёт один model request.
* Успешный model result создаёт одно Agent intention для Send Tool.
* Ack и realtime echo завершают outbox entry и сохраняют sent message key.
* Ошибка модели или отправки наблюдаема и не приводит к скрытому повтору.
