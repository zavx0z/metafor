# MF-406 — Ограниченное самоизменение Лады

## Зачем

Самоизменение должно быть частным случаем общего договора структурного агента,
а не специальным обходным путём Лады.

## Границы

* Только собственная структурная область через общий Graph-контракт.
* Явные ограничения ресурсов.
* Проверка Dark Oracle.
* Наблюдаемый исход.
* Действующая топология Лады по умолчанию не меняется.

## Критерии готовности

Операция использует утверждённые capability и policy задачи `MF-405` и не
получает дополнительных прав по имени агента.
