# AUD-010 — Убрать двойное перемещение UI-поверхности

## Зачем

Одно перемещение не должно выполнять одновременно быстрый и запасной путь.

## Подтверждённые факты

`moveRect?.(...) ?? setRect(...)` вызывает оба метода, потому что `moveRect`
возвращает `void`. Одинаковый путь существует в `pkg/ui/elements/runtime.ts` и
`../../quantum/bulk/web/index.ts`.

## Критерии готовности

* При наличии `moveRect` вызывается только он.
* Без `moveRect` вызывается только `setRect`.
* Проверено перемещение без изменения размера в обоих местах.
