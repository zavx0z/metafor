# AUD-013 — Автоматически проверять каждое изменение

## Зачем

Локально успешная проверка не запрещает принять следующее изменение с ошибкой.
Сервер должен проверять тот же минимальный договор проекта.

## Подтверждённые факты

В репозитории нет серверного сценария, выполняющего полный обязательный набор.

## Критерии готовности

Сервер запускает:

* `typecheck`;
* ожидаемые ошибки типов;
* тесты;
* TypeDoc Matrix, Engine, Dark, Boundary и Bulk без предупреждений;
* проверку Markdown и пробелов в изменениях.
