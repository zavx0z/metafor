# MF-417 — SVG-иконки Hamiltonian

## Зачем

В обычном Chrome-профиле кнопки заголовка Inspector существуют в раскладке,
но их SVG-иконки остаются прозрачными. Тот же UI-компонент в других контурах
работает, поэтому исправление должно оставаться в границе HTTP policy
Hamiltonian.

## Подтверждённые факты

* `data:image/svg+xml` загружается с HTTP 200.
* Chrome не декодирует этот SVG прямым `createImageBitmap` и `TextureLoader`
  использует `blob:` URL через `Image`.
* Действующий CSP Hamiltonian разрешает `img-src 'self' data:`, но запрещает
  `blob:`; Network показывает заблокированные fallback URL.
* Service Worker активен, а Window получил текущий `orchestration.js` с
  `Cache-Control: no-store`; обновление SW не является причиной дефекта.

## Решение владельца

Исправить дефект сейчас.

## Границы

* Разрешить `blob:` только для `img-src` Hamiltonian.
* Не ослаблять остальные директивы CSP.
* Не менять `TextureLoader`, Service Worker, раскладку и действия Inspector.

## Критерии готовности

* Bootstrap response содержит `img-src 'self' data: blob:`.
* Регрессионная проверка фиксирует это требование.
* Тесты Hamiltonian и root typecheck проходят.
* После полного перезапуска Hamiltonian обычный Chrome показывает обе кнопки
  Inspector без заблокированных `blob:` image requests.

## Результат

* CSP разрешает `blob:` только в `img-src`; остальные директивы не ослаблены.
* Focused host test: `1 pass`, `0 fail`, `55 expect()`.
* Root typecheck и штатная browser build-команда прошли.
* Владелец подтвердил появление иконок в исходном обычном Chrome. Отдельная
  финальная проверка `v62` также показала обе кнопки Inspector; снимок
  `/tmp/hamiltonian-mf417-mf418-v62.png`, SHA-256
  `09bb7c940eebb8c9229203367aff0dfbef397fd3575c11c23c1d1bc17950825d`.
