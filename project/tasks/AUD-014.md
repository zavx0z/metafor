# AUD-014 — Утвердить закон публикации корневого пакета

## Зачем

Корневой пакет не должен случайно публиковать исходники, задачи, проверки,
местные материалы и внутренние зависимости рабочего пространства.

## Подтверждённые факты

Корневой `package.json` объявляет `private: false`, экспортирует исходный
`index.ts` и зависит от `workspace:*`. Пробная упаковка содержит существенно
больше утверждённой поставляемой поверхности.

## Решение владельца

* Либо пакет остаётся внутренним и получает `private: true`.
* Либо публикуется только явная сборка из `dist`.

## Критерии готовности

`npm pack --dry-run` содержит только утверждённые файлы, а exports, типы и
зависимости указывают на реально поставляемые цели.
