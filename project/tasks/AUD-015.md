# AUD-015 — Актуализировать authoring и history документацию

## Зачем

Обзорные документы не должны отрицать уже реализованные peer-only Meta,
authoring RPC и read-only доступ к действующей Dark Force history.

## Подтверждённые факты

* Create CLI запрещает nested Meta repositories и создаёт отдельный peer Git
  repository с двухсегментным canonical `src`.
* Dark Monad публикует `meta.create`, `meta.matter.apply`,
  `meta.declaration.apply`, source/capability reads и runtime observation RPC.
* `dark.force.history.read` читает exact frontier и bounded range существующей
  Particle-history; clear/rewrite не опубликованы.
* Человеческий `meta.ts → live` authoring ещё не реализован и вынесен в
  `MF-408`.

## Границы

* Исправить только устаревшие утверждения; не менять код и public types.
* Не выдавать будущий internal Agent Atom authoring за выданную capability.
* Сохранить различие между CLI, trusted local RPC authoring и будущим
  человеческим source-to-live authoring.

## Критерии готовности

* `docs/ARCHITECTURE.md`, `docs/DARK.md` и
  `create-metafor/rules/metafor.md` не противоречат действующим owner contracts.
* Документация явно разделяет реализованное сейчас и будущую `MF-408`.
* `git diff --check` проходит.
