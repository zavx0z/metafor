# MF-300 — Выделить нематериализующую границу шаблона

## Зачем

Create MetaFor должен использовать существующий шаблон без немедленной записи
целевого каталога и без второго генератора.

## Границы

* Использовать существующие шаблоны Create MetaFor.
* Возвращать полный набор файлов до записи цели.
* Не дублировать поведение CLI.
* Не создавать второй генератор Monad.

## Решение владельца

Одна template boundary возвращает полный закрытый набор относительных
files. Существующий CLI и будущий RPC используют её же. Профиль
`standard` сохраняет CLI, а утверждённый RPC профиль `empty` оставляет
Fields, Process, Mass, Energy и Matter пустыми. Исполнитель: текущая задача Codex.

## Критерии готовности

Один чистый вызов строит и проверяет полный набор файлов без изменения
файловой системы целевого проекта.
