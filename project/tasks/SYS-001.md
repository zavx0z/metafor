# SYS-001 — Полный новый запуск после остановки

## Зачем

Повторный запуск должен создавать новый согласованный contour, а не частично
оживлять отдельный домен старого мира.

## Открытые вопросы

* Владелец внешнего управляющего контура.
* Предел попыток и задержка.
* Наблюдаемое состояние и сохранение первой причины отказа.
* Исход незавершённого Process при остановке.
* Отклонение позднего результата прежнего выполнения.

## Границы

Новый запуск создаёт все процессы заново и передаёт Matrix новый согласованный
срез Boundary. Частичное оживление запрещено.
