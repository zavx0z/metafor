# BND-004 — Миграция типа Field и ожидание enum default

## Зачем

Смена типа Field не должна оставлять несовместимые значения, а ожидание Variant
не должно теряться при перезапуске.

## Открытые вопросы

* Атомарно мигрировать существующие Atom values либо отклонять несовместимый
  `replace` до записи.
* Хранить pending enum default в Boundary до появления Variant.

## Критерии готовности

Закон одинаково работает при живом изменении и после холодного запуска.
