# MF-405 — Утвердить возможности структурного агента

## Зачем

Внутренний агент рабочей Вселенной не получает права внешнего цикла Codex
автоматически.

## Решение владельца

Нужно определить capability и policy для ограниченного Agent Atom subtree,
включая право планировать, проверять, предлагать и отдельно публиковать
структурное изменение.

Эта работа начинается только после доказательства полной функциональной
RPC-поверхности и рабочей сессии одного доверенного агента в `MF-104`.

## Границы

Наличие tool, команды, RPC или исполняемого файла не является выданной
возможностью.
