# MF-201 — Реализовать быстрый валидатор предложения

## Зачем

Недопустимое предложение должно быть отклонено до записи source и изменения
живого мира.

## Границы

Валидатор проверяет:

* ожидаемую revision;
* capability;
* graph scope;
* схему;
* запрещённые операции.

## Решение владельца

Первый slice принимает только закрытые versioned envelopes для
`meta.create` и Matter `add`, `move`, `remove`. Все остальные операции и
неизвестные поля запрещены. Исполнитель: текущая задача Codex.

## Критерии готовности

Каждый вид несоответствия даёт точную ошибку и не оставляет изменений.

## Проверка результата

Точечные tests доказывают `add`, `move`, `remove`, точные revisions,
capability, scope, закрытую JSON schema и запрет на все другие
operations. Общий TypeScript typecheck проходит.
