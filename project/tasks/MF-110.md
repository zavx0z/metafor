# MF-110 — Управлять изолированной ветвью через Interpreter

## Зачем

Утверждённая область исполнения должна быть доступна агенту через ограниченные
операции, а не через произвольный доступ к процессу или Git.

## Границы

* Создать, перечислить и отбросить ветвь.
* Сделать шаг вперёд и назад.
* Не записывать коммит и не отправлять изменения на сервер неявно.

## Критерии готовности

Interpreter предоставляет только утверждённые операции и доказывает отсутствие
изменений канонического мира без отдельного права.
