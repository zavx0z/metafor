# MTX-003 — Доказать структурное изменение при действующем Process

## Зачем

Изменение структуры во время исполнения не должно терять личность Atom,
завершать не то выполнение или запускать лишний Process.

## Границы

* Добавить дочерний Atom во время Process родителя и завершить прежнее
  выполнение до канонической записи результата.
* Проверить перемещение или продолжение Atom с сохранением личности.
* Создавать новое выполнение только при действительном изменении Process.
* Для каждого вида декларации проверить точный набор аннулированных выполнений.
* Не менять посторонние Atom.
