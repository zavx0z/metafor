# Артефакты задач

Здесь хранятся исходные файлы, на которые ссылаются накопитель и карточки.
Каждая задача использует постоянную директорию `artifacts/<ID>/` с тем же
номером, что в `BACKLOG.md`, `TODO.md` и `tasks/<ID>.md`.

## Что может находиться внутри

* снимки экрана и изображения;
* аудио и видео;
* исходные заметки и документы;
* журналы и результаты команд;
* примеры входных данных;
* выгрузки, профили и трассировки;
* ссылки и контрольные суммы крупных внешних файлов.

## Описание набора

Каждая непустая директория содержит собственный `README.md`:

```markdown
# ID — Артефакты

## Имя файла

* Источник:
* Дата:
* Версия проекта:
* Ожидание:
* Фактическое наблюдение:
* Чувствительные сведения:
* Внешний оригинал:
* Контрольная сумма:
```

Пустые поля удаляются. Для снимка экрана ожидание формулируется до получения
изображения, а фактическое наблюдение — после просмотра.

## Хранение

* Небольшой необходимый файл может храниться в Git вместе с описанием.
* Большое видео, аудио, трассировка или выгрузка требует отдельного решения о
  Git LFS либо внешнем хранилище.
* Внешний файл получает устойчивую ссылку и контрольную сумму.
* Секреты, ключи доступа и ненужные персональные данные не сохраняются.
* Временный файл удаляется при завершении задачи.
* Долговечное доказательство переносится к документу, проверке или другому
  постоянному владельцу результата.
