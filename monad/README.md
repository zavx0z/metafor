# @metafor/monad

Высокопроизводительный движок конечных автоматов на WebGPU для массовых симуляций агентов.

## Обзор

Эта библиотека реализует движок логических правил, работающий полностью на GPU (Compute Shader). Она позволяет симулировать тысячи сущностей (Монад), переходящих между состояниями на основе общего глобального контекста.

## Возможности

* **Zero-Copy Logic**: Правила компилируются в байт-код WGSL.
* **Массовый параллелизм**: Обработка 100k+ сущностей за кадр.
* **Общий контекст**: Агенты читают данные из глобальной кучи `Float32Array` / `Uint32Array`.

## Установка

```bash
bun add @metafor/monad
```

## Использование

### Запуск примера (Fullstack Server)

Проект включает Dev-сервер на Bun, который собирает клиентский код и запускает WebGPU демо в браузере.

```bash
bun run example
# или
bun run ./examples/server.ts
```

Откройте **<http://localhost:3000>** в браузере с поддержкой WebGPU (Chrome/Edge).

### Пример кода

```typescript
import { MonadSystem } from "@metafor/monad";

const system = new MonadSystem(gpuDevice);
// ... инициализация ...
```
